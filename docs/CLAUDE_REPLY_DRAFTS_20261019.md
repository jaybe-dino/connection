# 메일별 Claude 답장 초안

## 사용
https://admin.theprlist.net/recruitment → 크리에이터·메일 → 발신 계정 → 회신한 크리에이터 → 받은 메일에 답장 → Claude로 답장 초안 작성.

확정된 조건과 답장 방향을 입력하고 언어를 선택한다. AI 결과의 확인 사항을 읽은 뒤 `본문에 적용`한다. 기존 본문이 있으면 교체 확인을 받는다. 본문 수정 → 답장 초안 저장 → 별도 발송 승인 순서이며 AI 생성은 메일을 보내거나 발송 대기 초안을 만들지 않는다.

## 범위와 비용
- 기존 Anthropic 키/Claude 모델 설정을 그대로 사용. 새로운 키·자동충전·발송 한도 변경 없음.
- 선택한 공용 모집 연락처·계정·Gmail 대화의 실제 송수신 최대 8개, 각 본문 4,000자와 운영자 지시 최대 2,000자. 선택 회신 뒤 메일, 다른 대화, 공통 CRM 메모, 다른 브랜드 자료는 자동 포함하지 않음.
- URL과 긴 식별자 및 명시적 password/API key 필드는 문맥에서 가림. 본문에 불필요한 민감정보가 있으면 AI 대신 수동 작성 권장. 일반 텍스트 비밀정보 전부를 자동 탐지한다고 보장하지 않음.
- 수신 본문을 신뢰하지 않는 자료로 취급. 미확정 커미션·배송·보상·승인을 만들지 않도록 지시하되 결과는 담당자가 반드시 검토.
- 공용 모집 전체 rolling 24h 100회 예약 한도. 재시도 자동 호출 없음. 동일 request_id는 완료 결과 재사용. 실패·불명 상태에서 새 요청을 명시적으로 준비하면 별도 비용 발생 가능.
- 생성 시점의 계정·차단 확인 외에도 저장/실제 발송 시 기존 원래 계정 고정·차단·한도·승인 검사를 그대로 적용.

## 검수와 현재 외부 의존
API/청구 385개, UI 96개 통과, 관리자 빌드 통과. 정밀 검사에서 계정/다른 대화 제외·중복 요청·변경 요청 거부·차단·실패 후 자동 재호출 금지·메일 생성/발송 없음 확인. 로컬 화면 모사 응답으로 미리보기→본문 적용 검수. 실제 Anthropic 호출은 2026-10-19 잔액 부족 HTTP400이며 실생성 성공 검증은 충전 후 필요. 모사 응답은 운영 코드에 포함하지 않음.
