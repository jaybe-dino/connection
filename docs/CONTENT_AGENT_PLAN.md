# 콘텐츠 브리프 에이전트 기획 v1.0

시딩·캠페인 콘텐츠 제작 단계의 에이전트 — **아리의 9번째 담당자**.
발굴·수집 8종(기획 §4.3)이 크리에이터를 데려오는 담당이라면, 이 담당자는
**선정된 크리에이터가 좋은 콘텐츠를 만들게 하는** 담당이다.

## 1. 문제와 원칙

**문제.** 브랜드가 원하는 것(USP가 콘텐츠에 최대한 녹아들 것)과
크리에이터가 잘하는 것(자기 말투의 진정성 있는 콘텐츠), 그리고 법이 요구하는 것
(광고 표기·과대광고 금지)은 서로 당긴다. 대본을 주면 진정성이 죽고, 방치하면
USP가 빠지고, 둘 다 신경 안 쓰면 법적 리스크가 생긴다.

**원칙 3가지.**
1. **대본이 아니라 브리프** — 크리에이터에게 "말할 문장"이 아니라 "말할 거리"를 준다.
   USP는 브랜드 프로필의 **'고객의 언어'**(실제 리뷰에서 추출한 표현)로 변환해 제안 —
   광고 문구가 아니라 소비자 말투라서 자연스럽게 녹는다.
2. **법 준수는 기본값** — 브리프 생성 시점에 국가별 규정이 이미 반영돼 있고(필수 표기·
   금지 표현), 제출 시점에 자동 체크가 한 번 더 잡는다. 이중 그물.
3. **강제하지 않는다** — 브리프는 담당자 1:1로 전달되는 제안. 필수는 캠페인 '구체 조건'
   (길이·노출·표기)뿐. 검수도 통과/보완요청 2결과 유지(반려 없음).

## 2. 입력 → 출력

```
입력: 캠페인(제품·USP·조건·보상) + 브랜드 프로필 vN(고객의 언어·금지어·톤·크리에이터像)
    + 크리에이터(국가·언어·등급·카테고리·최근 콘텐츠 스타일) + 국가 규정 테이블
출력: 개인화 브리프(크리에이터 모국어) =
    훅 제안 3개 · USP 말하기 포인트(고객의 언어로) · 본인 경험 프레임 제안
    · Do & Don't(국가별 금지 표현 반영) · 필수 표기 문구 · 촬영 팁 · 조건 요약
```

생성은 번역이 아니라 **각자 언어로 직접 생성**(기획 §4.8 아리 발화 원칙).

## 3. 법리 가드레일 (컴플라이언스 엔진)

두 겹: **룰 엔진**(즉시·무료·결정적) + **LLM 검토**(맥락 판단·모호 케이스 승급).
숫자·규정은 초기값이며 **법무 검토로 확정**한다(기획 §9 오픈 이슈와 연결).

### 3.1 광고 표기 (경제적 대가 고지)
| 국가 | 근거 | 요구 표기 |
|---|---|---|
| KR | 표시광고법 · 공정위 추천보증 심사지침 | #광고 / #유료광고 — 첫 해시태그·본문 앞부분, 더보기 뒤 숨김 금지 |
| US | FTC 16 CFR Part 255 | #ad / #sponsored — clear & conspicuous |
| TH | 태국 소비자보호·FDA(อย.) 광고 규제 | #ad / #โฆษณา + 화장품 광고 사전 심의 대상 여부 확인 |
| VN | 베트남 광고법 | #quảngcáo / #ad |

### 3.2 화장품 금지 표현 (의약품 오인·과대광고)
- **의약품적 효능 금지**: 치료·치유·재생·항염·살균 계열 (전 언어 사전 보유:
  ko 치료/여드름 치료/아토피 완화… · en cure/treat/heal… · th รักษา… · vi trị/chữa…)
- **기능성 표현 제한(KR)**: 미백·주름개선·자외선차단은 식약처 기능성 인정 제품만 —
  캠페인에 `functional_claims`(허용된 기능성 목록)를 등록해 그 안에서만 통과
- **절대적 표현**: 100%·완벽·부작용 없음·최고 — 경고
- **브랜드 금지어**: 브랜드 프로필 banned_words — 브리프에서 배제 + 제출 체크

### 3.3 적용 지점 (이중 그물)
1. **브리프 생성 시**: 금지 표현이 애초에 제안에 안 들어감 + Don't 목록으로 명시
2. **제출 자동 체크 시**: 기존 4종(길이·노출·#ad·금지어)의 '#ad·금지어' 체크가
   이 엔진으로 교체·강화 — 위반 시 보완요청 + 원클릭 수정 제안

## 4. 흐름 (기존 시스템과의 연결)

```
캠페인 선정 확정
  → [브리프 에이전트] 크리에이터별 브리프 생성 (브랜드 프로필 vN 소비)
  → 브랜드 확인(선택 — 기본은 자율, 게이트 아님: 1:1 대화는 외부 발송이 아님)
  → 담당자 1:1 스레드로 전달 (크리에이터 모국어)
  → 크리에이터 질문 ↔ 아리 응답 (양방향 번역)
  → 제출 → 자동 체크(컴플라이언스 엔진) → 통과/보완요청
  → 30일 채점: 브리프 반영도·통과율·성과 → 브리프 전략 가중치 갱신 (평가 하네스)
```

게이트: 1:1 브리프 전달은 셀 내 대화라 게이트 밖(아리 자율). 단 브리프를 **셀 공지로
일괄 게시**할 때는 기존 PUBLISH 게이트를 탄다. 실패 조건: 특정 브랜드 브리프의
보완요청률 3회 연속 50%↑ → 해당 브랜드 브리프 자동 생성 중단·원인 보고(다른 에이전트와
동일 패턴).

## 5. 화면 반영 (기존 화면에 얹는다 — 신규 화면 없음)

- **콘솔 캠페인 등록**: USP 선택 아래 "컴플라이언스 미리보기"(대상 국가 규정 요약 +
  functional_claims 선택) · 지원자 탭 선정 시 "브리프 생성·검토" 버튼
- **크리에이터 담당자 탭**: 브리프 카드(접히는 형태 — 훅/포인트/Do&Don't/표기)
- **크리에이터 제출 탭**: 자동 체크 결과에 위반 상세 + 수정 제안 문구
- **어드민**: 분쟁 심판에서 "브리프 대조" 열람(브리프가 조건 분쟁의 증거가 된다)

## 6. 개발 범위 (이번 구현)

| 모듈 | 내용 |
|---|---|
| `api/compliance.py` | 룰 엔진 — 국가별 표기 체크 · 의약품적 표현(4개 언어) · 절대 표현 · 기능성 제한 · 브랜드 금지어. 위반 목록 + 수정 제안 반환 |
| `api/content_agent.py` | 브리프 생성 — Claude(claude-opus-5) 구조화 출력, 키 없으면 캠페인·프로필 조합의 결정적 폴백 브리프 |
| API | `POST /compliance/check` · `POST /campaigns/{id}/briefs` (생성) · `GET /campaigns/{id}/briefs/{creator}` |
| 테스트 | 룰 엔진 전 케이스 · 브리프 폴백 구조 · 엔드포인트 |

**하지 않는 것**: 영상 자동 분석(제출물의 발화 내용 검사 — P2, STT 필요) ·
브리프 강제(조건화) · 법률 자문 대체(초기값은 가드레일이며 법무 확정 전제).
