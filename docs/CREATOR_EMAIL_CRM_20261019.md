# 크리에이터별 이메일·기록 관리

## 사용 순서

https://admin.theprlist.net/recruitment → **크리에이터·메일**.

1. **Gmail 회신 가져오기**: 기존 Google 읽기 동의를 받은 공용 모집 계정에서 최근 30일 범위의 제한된 페이지를 동기화한다. 계정별 추가 건수·오류·남은 페이지를 표시한다. 실제 메일은 보내지 않는다. RUNNER_ENABLED나 기존 발송 한도를 변경하지 않는다.
2. 이메일·이름·핸들 및 상태로 연락처를 찾는다. 공용 모집의 발신 이력이 있는 이메일은 DB 연락처로 준비하며, 보유 creator_pool 프로필을 정확한 이메일 일치로 함께 표시한다. 다른 주소·별칭·사람을 자동 병합하지 않는다.
3. 아직 분류하지 않은 수신 대화는 **수신 원문 확인** 후 실제 크리에이터 모집 대화라고 확인 체크하고 등록한다. 일반 업무·보안 알림을 자동으로 크리에이터로 세지 않는다.
4. 연락처를 열면 수신·발신 원문을 시간순으로 보고, **이전 메일 더 보기**로 과거 기록을 읽는다. **이 받은 메일에 답장**을 누르면 해당 실제 Gmail 계정·스레드·RFC Message-ID를 고정한다. 다른 발신 계정으로 자동 교체하지 않는다.
5. 본문 작성 → **답장 초안 저장 · 발송 없음**. 저장 결과가 불명확하면 같은 요청으로 결과를 확인한다. 같은 요청은 새 초안을 중복 생성하지 않는다.
6. 저장된 초안의 **이 초안 검토·발송** → 발신·수신·본문 확인 → 실제 발송 체크 → **확인한 답장 1통 실제 발송**. 명시적 확인 전에는 보내지 않는다. 성공은 Gmail 접수이며 배달 보장은 아니다. 초안 취소는 기록을 남긴다.
7. 담당자·상태·다음 행동·기한을 DB에 저장한다. 변경 전후 값·작성자·시각을 별도 이력으로 보존한다. 내부 메모는 작성자·시각을 가진 별도 기록으로 저장하며 메일 본문으로 전송하지 않는다.
8. 같은 이메일에 연결된 브랜드·제품·제안 코드·캠페인·신청 이력을 확인한다. 기존 회신 작업함의 분류·메모도 보존해 표시한다. 회신과 모집 신청·참여 확정·검증 가입 청구를 혼동하지 않는다.

## 저장·권한 경계

052는 recruitment_contacts, recruitment_contact_notes, recruitment_contact_events, mail_reply_draft_requests만 추가한다. Gmail 원문은 기존 mail_threads/mail_messages를 재사용한다. 기존 12만 DB를 다시 반입하거나 멤버십/과금을 생성하지 않는다.

새 /admin/recruitment/contacts API는 실제 관리자 JWT만 허용한다. 모든 메일 조회·초안·발송·취소에서 공용 모집 공간과 선택 이메일의 소유 관계를 검증한다. 다른 브랜드/다른 연락처 메일 ID로 답장을 저장하거나 보낼 수 없다. 원본 Gmail 계정 연결, 기존 발신자 고정, 수신거부/연락 중지, Gmail 한도·간격을 유지한다.

실제 발송 불명은 review로 남고 자동 재전송하지 않는다. 동일 초안을 다시 전송해도 pending_gate → sending 조건부 변경이 막는다. 계정 중지/잔여 한도/간격으로 보내지 못하면 기존 정책에 따라 대기로 남는다. 전송 중·결과 불명은 취소하거나 새 초안으로 대체하지 말고 보낸편지함과 대조한다.

최근 메일 100건씩 커서 페이지, 제안/신청/메모/변경 이력은 화면에서 각각 최근 100건으로 표시한다. DB 기록을 지우는 기능은 추가하지 않았다. Gmail 동기화 범위 밖/외부 도구에서 직접 보낸 기록 전체가 자동 복원되는 것은 아니다. 첨부파일 다운로드·새 CRM 사람 병합·자동 답장 발송은 이번 범위가 아니다.

## 롤백과 검수

롤백 기준 태그 creator-crm-before-20261019 (f7ae131). 코드를 롤백해도 수신/발신/메모/변경/과금 기록은 보존한다. 새 테이블을 삭제하거나 운영 DB를 과거 백업으로 덮지 않는다.
테스트에서는 외부 Gmail 호출을 모사한다. 실제 이메일 발송 없이 원래 스레드/발신 계정 보존, 중복 초안 방지, 실제 발송 별도 확인, 차단/브랜드 격리, 불명 결과 재전송 금지, 과거 원문 커서 페이지를 검수한다.
