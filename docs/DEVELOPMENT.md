# 커넥션 개발 계획

인계 패키지(`docs/handover/`) 기준의 개발 준비 · 진행 문서.
기준 문서: 서비스기획안 v1.0 (§7 갭 분석, §8 로드맵) · 페이지맵 · 수집엔진 구현상세 명세.

## 스택 결정

인계 문서의 가이드("프로토타입은 화면 스펙의 정본, 프레임워크는 팀 선택")에 따라:

| 영역 | 선택 | 근거 |
|------|------|------|
| 수집 엔진 | **Python 3.11** + PostgreSQL + Redis(큐) | 구현상세 명세의 파이프라인/의사코드와 1:1 대응. 순수 로직(스코어·판정·dedup)은 stdlib로 구현해 테스트 가능. |
| 母 DB | **PostgreSQL** (주 원장) + 파생 인덱스 | 기술스택 명세 §5 그대로. |
| 크리에이터 앱 | PWA (프레임워크 미확정 — React 권장) | 같은 URL · 홈화면 설치 · 푸시. |
| 브랜드 콘솔 | 데스크톱 웹 (React 권장) | 나란히 구조 — 레일(8) + 아리 채팅 + 캔버스. |
| 공통 레이어 | 인증(패스) · 번역 · 게이트 엔진 · append-only 원장 · 알림 | 페이지맵 "공통 시스템 레이어" 참조. |

수집엔진과 앱은 **독립 병행** — 수집엔진 MVP는 앱과 별개로 먼저 돌릴 수 있다
(연결점은 母 DB → 후보 큐).

## 현재 구현 상태

### ✅ 완료 (이 저장소)

- 인계 문서 통합 (`docs/handover/`)
- 母 DB `creator_pool` 스키마 — 구현상세 명세 §1의 30+ 필드 전체 (`db/migrations/001_creator_pool.sql`)
- 수집엔진 MVP 골격 (`services/harvest/`):
  - **discover** — 시드 사전 구조 · 그래프 확장 파라미터 · 수렴 판정(§3)
  - **fetch** — 벤더 라우터(우선순위/폴백) · 배치/재시도 규칙(§4)
  - **enrich** — 이메일 추출 3단(정규식·난독화 대응) · 검증 파이프 · 국가 판정 가중치 합의(§5)
  - **dedup** — 블로킹 키 정규화 · 매칭 점수표 · 병합/검토 판정(§6)
  - **score** — 영향력 스코어 · 접촉 우선순위 · 등급 컷(§7)
  - **queues** — 큐/이벤트 계약 · 멱등성 규칙(§2)
  - **store** — creator_pool upsert · 상태 전이
  - 단위 테스트 (순수 로직, 네트워크 불필요)
- 앱 3표면 스캐폴드 (`apps/`)

### 로드맵 (기획안 §8)

- **M0 · 검증 (~2개월)** — 브랜드 1곳 · 태국 셀 1개 · 아리 L0~L1. OAuth 가입 + 셀 + 유가 캠페인 1종 + 수동 정산. 즉시 P0: 신고/차단 · 언어 변경 · 기본 알림(메일). 성공: 셀 30명 · 4주 발화 유지 · 판정 정확도 80%↑
- **M1 · 반자동 (3~5개월)** — 인바운드 판정·스윕 L2 · 채점 루프 · P0 완성. 성공: 브랜드 3곳 · 승인 평균 4시간 내
- **M2 · 자동+확장 (6개월~)** — L2 승격(브라이어) · 어필리에이트 엔진 · 리포트 · 두 번째 국가. 성공: 브랜드 10곳 · 갱신율 80%↑

## 수집엔진 운영 파라미터 (설계 기준값)

구현상세 명세의 숫자 — 운영에서 캘리브레이션. 코드의 `harvest/config.py`에 반영.

- 그래프 확장: `seed_pages_per_tag=50`, `commenters_per_video=top3×200`, `suggested_depth=2hop`, `expand_fanout_cap=30/계정`
- 수렴 판정: 최근 10k 중 신규율 < 3%가 3배치 연속 → 전수 근접으로 종료
- Fetch: `batch_size=500`, 재시도 3회 지수 백오프(2s→8s→30s), 429는 감속+벤더 폴백, 404는 즉시 `EXCLUDED`
- 국가 판정 가중치: account_region 0.40 · phone_country 0.25 · bio_lang 0.15 · caption_lang 0.15 · active_hour_tz 0.05, conf<0.6 → recheck
- Dedup: 합산 ≥1.0 자동 병합 · 0.6~1.0 사람 검토
- 비용 목표: 계정당 30~120원 (100만 계정 워크드: API 직접비 ~$21,000~35,000 + 라이선스)

## 하지 않는 것

- 자체 LLM · 파인튜닝 (라벨 1만 건 전) / 범용 CRM / 반출·라이선스 기능 (범위 제외)
- 로그인 우회 · CAPTCHA 무력화 · ToS 위반 스크래핑
- 탐색 피드 · 셀 랭킹 (셀은 브랜드 단독 세계)
