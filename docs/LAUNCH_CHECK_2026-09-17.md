## 공개 화면에서 제외한 기존 프로토타입
- 가상 가입자 수·가상 매출·가상 학습 완료·자동 생성된 가상 답장.
- SNS 검증, 자동 후보 수집, 크리에이터 캠페인 신청, 셀 커뮤니티, 크리에이터 대금 지급.
- 기존 GLOWLAB 고정 러너는 중지. 검증되지 않은 자동 발송·드라이런 결과를 운영 성공으로 표시하지 않는다.
- 기존 코드는 복원·개발을 위해 남기되 공개 UI에서 접근 경로를 제공하지 않는다.

## 전체 오픈 전 남은 작업
1. TikTok/Meta 승인과 실제 계정 검증 → 멤버십 → 가입 과금까지 연결.
2. 실제 후보 목록·캠페인 참여·검수·크리에이터 지급 구현 및 역할별 권한 검증.
3. 답장 자동 수신 서비스·DNS·발신 검증·중복 수신 방지. 현재는 연결한 Gmail에서 확인.
4. 카드 실승인/취소·환불 운영 검증. 1,000원 미만 월 청구의 이월/수납 정책 확정.
5. 운영자의 브랜드 승인 및 초대 링크 전달 업무. 현재 자동 안내 메일 없음.

## 검증 방법
- 개인/운영 DB와 분리한 임시 PostgreSQL에서 마이그레이션과 테스트 실행.
- API·결제·아웃리치·학습 테스트 109개 통과(기존 73 + 결제/아웃리치 17 + 학습/보안 19).
- signup/console/creator-app/admin 빌드 통과.
- 브라우저 학습 테스트는 외부 AI·사이트 응답을 고정한 별도 로컬 환경. 운영 AI의 실제 동작 확인 결과는 배포 후 별도 기록.
- 실제 수신자에 대한 발송·실제 카드 결제는 하지 않았다.

## 운영 환경 확인 및 제한
- Railway 배포 및 DB 마이그레이션 성공. `/gates`, `/db/creators`, 브랜드 Gmail 조회는 미로그인 401 확인.
- 실제 Anthropic 모델 조회는 성공했으나 분석 호출은 credit balance 부족으로 거절됨. 키 설정 여부만으로 AI 사용 가능이라고 판단하지 않는다. 계정 충전 후 실제 분석 성공 재검증 필요.
- 자동 분석 중단 시 직접 입력으로 가입 신청 가능. 콘솔에서도 수동 프로필 저장 가능. 수동 입력을 AI 학습 완료라고 표시하지 않는다.
- 신청의 약관 동의·정보 확인 시각을 저장한다.
- 모노레포 루트 빌드에서 앱 내부 rewrite 설정이 적용되지 않아 `/signup`이 404였음. 정적 경로 디렉터리를 빌드 산출물에 생성해 수정.
- 임시 모바일 viewport 설정이 브라우저에 반영되지 않아 390px 실화면 검증은 완료하지 못함. 모바일 반응형 CSS는 포함되어 있음.
