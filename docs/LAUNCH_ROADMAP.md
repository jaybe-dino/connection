## Phase 1 · 실서비스 기반 — 2~3주 ("데모"를 "제품"으로)

지금 시스템은 GLOWLAB 데모 시드 위에서 도는 단일 브랜드 데모다.
실서비스가 되려면 **진짜 계정·진짜 브랜드 분리·진짜 발송**이 필요하다.

### 🤖 개발 (우선순위 순)

1. **실인증 체계** (1주) — 실서비스의 관문
   - 크리에이터: 이메일 매직링크 로그인(SNS OAuth 승인 전 임시) → 틱톡/인스타 OAuth로 교체
   - 브랜드 콘솔: 이메일+비밀번호 로그인, 신청 승인 시 계정 자동 발급·초대 메일
   - 어드민: 비밀번호 + TOTP 2FA (ADMIN_PLAN.md 설계)
   - 세션 토큰(JWT) 전면 적용 — 지금의 `c-mai`/`X-Admin-Id` 하드코딩 제거
2. **멀티테넌시 정리** (3~4일)
   - 데모 시드 분리(데모 모드 플래그), 브랜드별 데이터 격리 검증(셀·캠페인·게이트·원장)
   - 신청 승인 → 브랜드 온보딩(프로필 위저드 → 아리 세팅 → 셀 생성) 완결
3. **브랜드 발신 이메일 P0** (1주) — BRAND_SENDER_PLAN.md 트랙 A(지메일 OAuth)+B(도메인 인증)
4. **틱톡샵 대량발송 P0** (1주) — TIKTOKSHOP_DISPATCH_PLAN.md 반자동(CSV) 모드
5. **보안·운영 하드닝** (3~4일)
   - CORS 화이트리스트(도메인 확정 후), API 레이트리밋, 입력 검증 재점검
   - DB 자동 백업(Railway 설정+덤프 잡), Sentry 에러 트래킹, 업타임 모니터(UptimeRobot)
   - 시드/테스트 데이터 프로덕션 차단
6. **품질**: 위 전부 테스트 + E2E 확장, main 머지·릴리스 브랜치 체계

### 🧑 사장님 (병행 — 대부분 "접수하고 기다리는" 일)

| 할 일 | 소요 | 왜 지금 |
|---|---|---|
| **도메인 구매·확정** (예: connection.app) | 30분 | 인증 메일·OAuth 콜백·약관 페이지·CORS 전부 이것 대기 |
| 회사 정보 전달(상호·주소·연락처·대표) → 🤖가 개인정보처리방침·약관 초안 → 검토 | 1시간 | 틱톡·Meta 심사 필수 제출물 |
| **틱톡샵 파트너 신청** (partner.tiktokshop.com) | 1시간 | 심사 2~4주 — 대량발송 P1 전제 |
| **틱톡 Login Kit + Meta 비즈니스 인증** 접수 | 2시간 | 심사 1~3주 — 크리에이터 실가입 전제 |
| SendGrid 가입 + 발신 도메인 인증 시작 | 30분 | 워밍업 2~4주 시계가 여기서 시작 |
| 가입 플로우 데모 영상 녹화 (심사 제출용) | 30분 | 틱톡·Meta 심사 요건 |
| 결정 3개: main 머지 승인 · P0 순서(이메일 먼저 추천) · 데모 시드 유지 여부(영업용 데모 환경 별도 유지 추천) | 10분 | 🤖 착수 조건 |

**Phase 1 완료 판정**: 새 브랜드가 가입 신청 → 승인 → 자기 계정으로 콘솔 로그인 →
자기 발신 이메일 등록 → 실제 크리에이터에게 첫 메일/초대가 나가는 것.

## Phase 2 · 파일럿 — 2~4주 (브랜드 1곳 · 크리에이터 10~50명 실전)

목표: 돈이 오가는 실제 캠페인 1개를 처음부터 끝까지 완주.

### 🧑 사장님 (여기서부터 운영이 주역)
- **파일럿 브랜드 1곳 섭외** (지인 브랜드·자사 브랜드 추천 — 조건 관대하게)
- 제품·샘플 물량 확보, 배송 체계(초기엔 브랜드 직발송+송장 수기)
- 태국 크리에이터 **시드 리스트 50~100명** (수집엔진 결과 + 수동 큐레이션)
- **운영 일과 정착**: 아침 게이트 승인(10분) → 신고·분쟁 SLA 확인 → 주 1회 지급 승인
- 첫 정산 1회 수동 실행(계좌이체) — 자동화 전 검증
- 벤더 키 구매(ScrapeCreators·EnsembleData·Apify·ZeroBounce, 월 ~$200)

### 🤖 개발 (파일럿 지원 모드)
- 수집엔진 실가동: 벤더 키 캘리브레이션 → 해시태그 스윕 → 母 DB 1만 계정
- 아웃리치 첫 실배치 (워밍업 준수, 게이트 승인 하에)
- 파일럿 중 나오는 버그·UX 개선 즉시 반영 (주 2~3회 배포)
- 운영 대시보드 보강: 아리 주간 리포트, 지표 알림(Slack)

**Phase 2 완료 판정**: 캠페인 1개 완주(모집→선정→배송→제출→검수→정산),
스팸 신고 0, 크리에이터 이탈 없이 셀 유지, 브랜드가 "계속 쓰겠다"고 말하는 것.

## Phase 3 · 정식 오픈 — 이후 4~8주

### 🤖 개발
- **결제·과금**: 플랜(Starter/Growth/Enterprise) 구독 결제 (토스페이먼츠 or Stripe)
- **정산 자동화**: PingPong/Wise 연동 — PAYOUT 게이트 승인 시 실지급
- 틱톡샵 **P1 자동 모드** (파트너 승인 후 API 연동)
- **앱 스토어 출시**: 보관 중인 Expo 코드베이스 활성화 → iOS/Android 심사
- 스케일: DB 인덱스·커넥션 풀, 작업 큐 분리, CDN, 50만 계정 대비
- 카카오 알림톡(브랜드 알림), 다국어 랜딩 페이지

### 🧑 사장님
- 법무 검토: 개인정보 국외이전(태국 크리에이터 데이터), 태국 PDPA, 광고 표시법
- PingPong KYB 서류, 카카오 비즈니스 채널·딜러사 계약
- 애플/구글 개발자 계정($99/년·$25), 앱 심사 대응
- 가격표 확정, 영업 시작 (데모 환경 = 영업 무기)

**정식 오픈 판정**: 유료 브랜드 3곳+, 자동 결제·정산 가동, 앱 스토어 게시.

```
                └─→ 메일 도메인 인증(🧑) ──→ 워밍업 2~4주 ──→ 실아웃리치

실인증(🤖) ──→ 멀티테넌시(🤖) ──→ 파일럿 브랜드 온보딩(🧑)
```
