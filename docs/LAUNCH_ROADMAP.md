# theprlist 오픈 기준과 개발 순서

기준일: 2026-09-19. 이번 사용자 설명을 현재 제품 방향의 기준으로 삼습니다.
이 문서는 개발할 목표이며, 완료 기능 목록이 아닙니다. 과거 데모 로드맵은 archive에 보관했습니다.

## 서비스의 목표

한국 브랜드가 제품에 맞는 TikTok Shop 어필리에이트 크리에이터를 지속적으로 확보하고, 자기 브랜드의 PR 리스트 커뮤니티에서 관계·캠페인·협상을 운영하게 돕는 AI 서비스.

핵심 성과는 메일 발송량이 아니라 **적합한 크리에이터의 브랜드별 검증 가입, 캠페인 참여, 콘텐츠 게시와 재참여**입니다. 판매 성과는 실제 TikTok 데이터가 연결되기 전에는 추정치와 확정치를 분리합니다.

## 완료되어야 할 사용자 흐름

브랜드 가입·승인 → 브랜드·복수 제품 등록/학습 → 담당자 사실 확인 → 제품별 캠페인 작성 → 적합한 후보 추천 → 아웃리치 승인·발송 → 브랜드 전용 PR 리스트 가입 → 본인/계정 검증 → 다국어 커뮤니티·1:1 대화 → 지원·선정·조건 합의 → 샘플·콘텐츠·TikTok 식별자 제출 → 검수·성과 확인 → 검증 가입 이용료 월마감·결제.

브랜드 서비스 로그인과 Google 메일 권한, TikTok 계정 권한은 별도입니다. 국가와 플랫폼 자격에 따라 가입 가능 여부와 캠페인 참여 가능 여부도 구분합니다.

## 이번 점검의 판정

**정식 상용 오픈 보류. 브랜드 신청 접수 및 담당자 동반 메일링 실험은 가능하나 전체 제품 파일럿은 아직 불가.**

- 운영 웹·API·DB는 정상 응답.
- 브랜드 홈페이지 1페이지 분석·프로필 저장·AI 초안 작성 기반이 있음.
- 브랜드 Gmail 실발송(이전 자체 테스트) 및 이번 실제 받은편지함 10통 동기화 확인.
- 제품 카탈로그·브랜드 커뮤니티·실제 크리에이터 가입·제품별 모집을 완주하는 경로가 없음.
- 데모 캠페인/셀/번역 API가 있다고 브랜드가 사용할 수 있는 제품 기능으로 간주하지 않음. 현재 해당 레거시 API는 관리자 전용.
- 이번 접근 통제 보완 후 자동 테스트 273개 통과. 모의 테스트를 외부 플랫폼 실연동 성공으로 간주하지 않음.

## 데이터와 권한의 기준

브랜드 아래에 제품, 캠페인, 커뮤니티, 멤버십, 발신 계정, 청구서를 둡니다. 전역 크리에이터 풀에는 출처와 최근 확인 시각을 기록하며, 비공개 대화·협상·이메일은 전역 풀에 섞지 않습니다.

- Brand → Product → Campaign → Application → Participation → Deliverable.
- Brand → Community → Channel → Message / Brand + Creator → Private conversation.
- Creator identity → Brand membership → Verified signup usage → Monthly invoice → Payment/refund.
- Candidate recommendation → Outreach recipient → Invite attribution → Verified membership.
- 모든 읽기·쓰기·첨부·내보내기·비동기 작업에 브랜드 권한을 적용합니다.
- 회원이 캠페인 지원 시 임의 creator_id로 다른 사람을 사칭할 수 없어야 합니다.
- 광고 코드, 배송 주소, 협상 금액은 공개 채널에 노출하지 않습니다. 코드 종류는 TikTok 실제 업무 절차에 맞춰 확정합니다.

## AI 성능을 검증하는 방법

출시 전 브랜드별 담당자가 평가한 후보 세트를 만듭니다. 제품·시장별 최소 30명씩, 개발에 사용한 후보와 최종 평가 후보를 분리하는 것을 제안합니다. 다음 수치는 아직 달성한 실적이 아니라 파일럿 합격 기준 초안입니다.

- 상위 10명 중 담당자 적합 판정 7명 이상; 추천마다 근거 링크·확인 시각·미확인 항목 제공.
- 연락 금지/중복/수신거부 후보 제외 100%; 사실과 다른 제품 효능·성과 숫자 생성 0건.
- 제품 변경 시 추천/메일에 새 제품 버전이 반영되고 다른 브랜드 정보가 섞이지 않음.
- 번역 평가에서 가격·수수료·기한·코드 원문 보존 100%; 중요한 조건은 원문과 확인 UI 제공.
- 추천→발송→답장→가입→선정→게시 전환율과 **검증 가입 1명당 AI·데이터·메일 비용** 측정.
- 외부 홈페이지·메일·메시지를 시스템 지시로 실행하지 않음. AI는 허용된 브랜드 자료만 참조.
- 초기에는 후보/캠페인/메일 초안을 사람이 확인. 자동 발송은 캠페인별 승인된 대상·예산·일일 상한 내에서만 허용하고 전체 중지 버튼 제공.

## 이메일과 웜업의 제품 약속

웜업을 '스팸함에 가지 않음' 또는 '자동으로 평판 보장'이라고 판매하지 않습니다. SPF/DKIM/DMARC 정렬, 실제 수신 의사가 있는 연락처, 소량 발송, 반송/신고 관측과 즉시 중단을 지원하는 발신 운영 기능으로 정의합니다. 가짜 회신·열람을 생성하지 않습니다.

현재 Google 수신 범위는 최근 30일 INBOX, 10개/회, 화면이 열려 있을 때 60초 간격입니다. 첨부파일 및 읽음/삭제 상태 동기화는 제외합니다. 서버 워커로 전환하기 전에는 24시간 자동 수신으로 안내하지 않습니다.

공개 오픈 전에 Google 제한된 Gmail 읽기 범위 검증·보안 평가 적용 여부와 실제 앱 승인 상태를 확인해야 합니다. 자체 계정 연결 성공이 모든 신규 브랜드의 OAuth 승인 성공을 뜻하지 않습니다.

## 과금 기준 — 기존 지시 유지

- Starter 등 요금제와 월 고정요금 없음.
- **브랜드별 신규 검증 가입 1명당 5,000원, 부가세 포함, 월 단위 합산.** 매달 전체 회원 수에 반복 부과하는 구독 방식이 아니며, 같은 브랜드 중복 가입은 재과금하지 않는다.
- 현 구현: 같은 브랜드+크리에이터 중복 과금 방지, 데모 제외. 실제 회원 가입/검증 UI와 이벤트 연결은 미완성.
- 제품 여러 개 지원·탈퇴 후 재가입은 같은 브랜드에서 새 가입 과금으로 만들지 않음. 다른 브랜드에 처음 가입하는 경우의 과금은 브랜드별 기준을 유지.
- 부정/잘못된 검증 취소 시 원장을 삭제하지 않고 조정 내역을 기록하도록 구현해야 함.
- 현재 월청구서는 조회 시 지난달을 마감하는 방식이고 자동 카드 출금이 아님. 예약 월마감·통지·납부/미납 관리 필요.
- 현재 1,000원 미만 카드 결제 차단: 5,000원 단가에서는 1명만 가입해도 결제 가능하므로 실질 영향 없음(과거 저단가 기록 청구서만 해당).
- 1,000명 가입 매출은 50,000원. AI·데이터·발송비가 이를 초과할 수 있으므로 캠페인별 비용 상한과 원가 측정 필수. 사용자 승인 없이 가격 변경하지 않음.

## 구현 순서와 합격 조건

| 순서 | 작업 묶음 | 합격 조건 |
|---|---|---|
| 0 | 보안 누락, 현황/과장 문구 정리 | 비로그인·다른 브랜드가 데이터/내보내기/운영 지표를 변경 못함 |
| 1 | 제품 학습 + 브랜드 PR 리스트 + 크리에이터 검증 가입 | 새 브랜드/새 제품/새 크리에이터로 가입 완료, 5,000원 이벤트 정확히 1건 |
| 2 | 제품 캠페인 + 커뮤니티/DM + 번역 | 다른 언어 두 계정의 대화·지원·선정·조건 확인, 브랜드 간 접근 차단 |
| 3 | 추천 AI + 후보 DB + 모집 자동화 | 실제 후보 평가 통과, 근거 있는 맞춤 메일, 초대 추적/수신거부/재시도 중복 방지 |
| 4 | 캠페인 수행 + TikTok 단계 연결 | 제품/협업 식별자·선정·샘플·콘텐츠·조건 합의까지 한 캠페인 완주 |
| 5 | 월마감/소액 이월/실결제 + 운영 복구 | 월말 재실행 무중복, 결제/취소 대사, 백업 복구 및 장애 대응 확인 |

이 순서는 의존 관계입니다. 메일링만 개선하고 가입·커뮤니티 구현을 뒤로 미루면 서비스 핵심 가치와 과금 모두 검증할 수 없습니다.

## 공개 전 리허설

운영 데이터와 분리된 환경에서 새 브랜드 2개, 제품 각 2개, 서로 다른 언어의 크리에이터 계정으로 다음을 완료한 뒤 초대형 파일럿을 진행합니다.

1. 브랜드 온보딩과 제품별 자료 확인 → 캠페인 2개 개설.
2. 검증된 후보로 초대 발송 → 브랜드 PR 리스트 가입 → 중복 없이 이용료 기록.
3. 공지/공개 대화/DM 자동 번역 → 지원·선정·수수료 합의.
4. 필요한 코드·샘플·콘텐츠 제출 → 검수·종료.
5. 월마감·소액 이월·결제 성공/실패/취소 → 원장 대사.
6. 다른 브랜드 접근·수신거부·권한 해제·워커 재시작·중복 웹훅·AI 장애·삭제 요청 처리.

실제 카드 승인/취소는 별도 승인받은 소액 거래로 검증합니다. 크리에이터에게 무단 테스트 메일을 보내지 않습니다.

## 외부 의존성과 아직 확인할 것

- 첫 모집 국가/지원 언어: 사용자 답변 대기. 한국 브랜드라는 이유로 한국 TikTok Shop 시장을 가정하지 않음.
- TikTok Shop 파트너/판매자 권한과 허용 API, Google 공개 앱 검증 상태.
- 실제 파일럿 브랜드·제품·담당자 확인된 후보 데이터.
- '코드 번호'의 업무상 종류: Shop ID, 어필리에이트 협업 ID, 광고 사용 코드 등을 혼용하지 않음.

공식 참조: [TikTok Affiliate Integration](https://partner.tiktokshop.com/docv2/page/affiliate-integration), [파트너 권한](https://partner.tiktokshop.com/docv2/page/partner-authorization-guide), [Google Gmail 범위](https://developers.google.com/workspace/gmail/api/auth/scopes), [Gmail 발신자 가이드](https://support.google.com/mail/answer/81126).
