# theprlist 오픈 체크리스트 (2026-09-26 기준)

개발·격리 검증은 커밋 이력과 `docs/DEV_STATUS_2026-09-20.md`에 증거와
함께 완료 기록되어 있다. 이 문서는 **오픈 선언 전에 운영에서 사람이
확인해야 하는 항목**만 다룬다. 개발 샌드박스는 운영 도메인 접근이
차단되어 있어(egress 제한) 아래는 소유자 또는 Codex가 수행한다.

## 0. 자동 확인 스크립트 (5분)

배포 후 아무 머신에서:

```bash
EXPECT_COMMIT=<배포한 커밋 sha> bash scripts/ops/open-check.sh
```

읽기 전용(GET만)이며 다음을 한 번에 판정한다:
API·DB 정상, **배포 커밋 일치**(/health의 commit — Railway가
RAILWAY_GIT_COMMIT_SHA를 주입), 콘솔·크리에이터 앱에 P0 엔진 반영
(관리자 브랜드 선택·인박스 더보기·매직 전달 마커), 소개 사이트의 매직
전달 코드, 러너 수신 동기화 활성 + 승인 자동 발송 차단(SEND_RESUME=0).
FAIL이 있으면 각 줄의 사유대로 조치(대부분 "구버전 배포 → 재배포" 또는
Railway 환경변수).

## 1. 매직링크 실메일 1회 (필수 — 크리에이터 가입 진입로)

- app.theprlist.net 미로그인 → 본인 이메일 입력 → "로그인 링크 받기"
- 수신 메일의 링크가 **app.theprlist.net**으로 열리고 클릭 1회에 로그인
- 새로고침해도 로그인 유지, 같은 링크 재클릭은 만료 안내
- (선택) 초대 URL `app.theprlist.net/?brand=<슬러그>`로 시작하면
  로그인 후에도 해당 브랜드 합류 카드가 유지되는지

## 2. 관리자 콘솔 실검수 (필수)

- console.theprlist.net 관리자 로그인 → **브랜드 선택 화면**이 먼저 뜸
- 실브랜드 선택 → 홈/헤더에 `관리자 · <브랜드>` 표시, 로고·제품·캠페인·
  학습·커뮤니티·인박스·청구가 전부 그 브랜드로 연결
- "전환" → 선택 화면 복귀, 다른 브랜드 선택 시 이전 브랜드 데이터 혼입
  없음. 데모(glowlab)는 "데모 브랜드" 라벨로 명시 선택 시에만

## 3. Gmail 러너 가동 (필수)

- 어드민 → Gmail 운영: 실행기 가동 중, 수신 동기화 카운터 증가,
  "오래됨" 경고(마지막 2026-09-18) 해소
- 자동 발송은 차단 상태(GMAIL_SEND_RESUME_ENABLED=0) — 발송은 승인 후
  수동 흐름만. 자동 재개를 원할 때만 이 변수 제거

## 4. 재설정 메일 1회 (권장)

- theprlist.net/account.html → 재설정 요청 → 메일 수신 → 새 비밀번호
  → 기존 세션 로그아웃 확인 → 재로그인
