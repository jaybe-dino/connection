## 이번 반영
- 가입당 5,000원(부가세 포함), 월별 합산 청구 — 2026-09-20 확정 — 50원은 과거 도입가 정책이며, 그 시기의 미청구 기록은 50원 그대로 보존(022). 신규·미청구 가입부터 적용하며 이미 발행한 청구서 금액은 보존한다.
- 청구 금액은 가입 건별 저장 단가 합계. 단가 변경 후에도 과거 청구 금액을 다시 계산하지 않는다.
- NICEpay 운영키·카드 통보 주소 연결 완료(이전 배포). 실제 카드 승인 테스트는 아직 실행하지 않았다.
- NICEpay 공식 오류코드 3041: 카드 1,000원 미만 승인 불가. 소액도 월별 청구 내역은 보존하며 카드 버튼은 제공하지 않는다. 이월/별도 수납 방식은 사용자 결정 대기.
- 메일링: 수신자 이메일 최대 20명 입력 → 제목·본문 저장 → 상세 검토 → 승인하고 발송.
- 같은 브랜드 동일 이메일 90일 내 재발송 차단, 수신 거부 링크와 제외 목록. 타임아웃은 확인 필요로 남기고 자동 재발송하지 않는다.
- 발송 성공은 Gmail 메시지 ID가 반환된 경우만 기록. 일일 한도 초과·연결 없음은 발송 대기로 유지한다.
- 인박스 조회로 발송되던 부작용 제거. 답장도 명시적으로 승인하고 발송한다.
- 답장은 현재 Gmail에서 확인한다. 콘솔 자동 수신은 아직 미설정이다.

5. TikTok/Meta: 파트너·로그인 앱 심사 및 API 자격 확인 후 연결. 현재 일부 수집·에이전트 화면은 데모다.
6. 운영 전 전체 브랜드 격리·게이트 권한·수집 러너 점검. 기존 러너는 GLOWLAB 하드코딩과 메모리 작업 상태가 남아 있으며 새 메일 발송 큐와 별개다.
