# 브랜드 Gmail 아웃리치와 웜업 점검

2026-09-18 KST. 기존 QA 후 사용자가 요청한 발신/수신/웜업 집중 점검.

## 실제 확인

- 운영 콘솔 계정 `jaybe@dinostudio.kr`, 브랜드 식별자 `glowlab`에 Gmail이 연결되어 있음.
- 본인 대상 테스트 1통을 실제 콘솔에서 저장 → 검토 → 발송. 제목 `theprlist-QA-20260918 브랜드 Gmail 발송 확인`.
- 23:45 KST Gmail 받은편지함 도착 확인. Gmail 상세정보의 보낸사람·답장·수신 주소 모두 `jaybe@dinostudio.kr`.
- 콘솔 수신자 상태 `발송 완료`, 당일 카운터 `1 / 2`, 남은 한도 1통 확인. 외부 크리에이터에게는 보내지 않음.
- 자체 수신 확인은 다른 수신 도메인의 배달률/스팸 분류 보장이 아님.
- 운영 `INBOUND_REPLY=0`, 수신 인증 키와 SendGrid 키 없음. 따라서 답장은 브랜드 Gmail으로 돌아가며 theprlist 인박스로 자동 수집되지 않음.
- Google 권한은 gmail.send + openid/email. 받은편지함 읽기 권한 없음.
- 운영 브랜드 프로필은 v0(미저장). 맞춤 AI 메일 작성에는 브랜드 정보 입력이 먼저 필요.
- 실제 Anthropic을 사용한 새 compose API 검증: 격리 DB의 공개 서비스 소개 정보로 HTTP 200, 제목/본문 367자 생성, sent=false, 발송 배치 생성 0건.
- 회사 도메인 SPF에 Google 포함, DMARC p=none 레코드 확인. SPF 레코드만으로 인증/평판 전체 통과 판정하지 않음.

## 반영한 변경

- 별도 서비스 상태 메뉴 제거, 아웃리치와 대화 내역을 하나의 화면으로 정리.
- 저장한 브랜드 프로필 + 제안 내용을 사용하는 AI 메일 초안 버튼/API. 사용자 확인 없이 저장하거나 발송하지 않음. 브랜드별 일일 20회 제한.
- 발신자 UI가 마지막 연결 계정을 표시하던 오류 수정. 실제 발송에 사용하는 첫 연결 계정과 일치.
- 웜업 한도를 연결 후 경과일 대신 실제 발송한 날 기준으로 증가. 첫날 2통, 이후 4/6/8/12/16/20통. 전달 피드백 연결 전 상한 20통.
- 발송 중지/재개, 당일 한도와 남은 한도, 불확실 발송 시 자동 중지. 기존 불확실 메일은 재발송하지 않음.
- 전달률/반송률/평판 미측정 표시. Gmail 접수와 실제 전달을 구분.
- 프런트/서버 배포 시차에 새 필드가 없으면 확인 중 표시.

참고 구현: 별도 `Build Glovek Outreach MVP`의 `src/lib/services/ramp.ts`, `ramp-sender.ts`, `health.ts`를 읽기 전용으로 참고. Glovek 레포 변경 없음. 해당 MVP의 seed 발송·피드백·DNS 자동화를 복사해 연결했다고 주장하지 않음.
