## QA에서 수정한 문제

1. 프로필 값을 지워도 기존 데이터가 남는 문제: 명시적 빈 값은 삭제, 생략된 필드는 유지. 실제 실패 재현 후 회귀 테스트 통과.
2. 알 수 없는 필드만 보내도 불필요한 프로필 버전 생성: 유효 필드만 검증하고 잘못된 요청 거절.
3. 빈 홈페이지 주소로 분석 버튼을 눌러도 안내가 없는 문제: 입력 안내 추가.
4. 아웃리치 조회 실패와 빈 목록을 구분하지 못함: 로딩/실패/빈 목록을 구분하고 오래된 요청의 실패 응답이 새 상태를 덮지 않도록 처리.
5. 관리자에 하드코딩된 사용자명과 ‘전원 OAuth 검증’ 표시: 실제 의미에 맞게 변경, 저장된 테스트 데이터가 실적이 아님을 표시.
6. 관리자 인증 상태 조회 실패 시 우회 버튼 노출: 실패 시 우회 버튼 숨김.
7. AI 공급자 일시 실패 안내 개선 및 안전한 오류 종류/상태 코드 기록. 첫 실패 원인은 이전 코드가 예외를 기록하지 않아 확정 불가. 공급자 가용성 자체를 해결했다고 주장하지 않음.
