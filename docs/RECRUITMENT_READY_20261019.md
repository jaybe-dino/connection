## 운영 순서

1. https://admin.theprlist.net/pool 에서 반입 상태 complete와 후보 수를 확인.
2. https://admin.theprlist.net/recruitment 회사 관리 브랜드 표에서 고객 브랜드와 커뮤니티를 선택.
3. 제품 정보·USP·보상·대상 국가·물류·가이드·일정을 최신 자료로 확정. 과거 마감일은 재사용하지 않는다.
4. 제품별 매핑을 선택하고 집군 추천. 이번 원본은 언어 미상이라 언어 필터는 비워 둔다. 미검증 이메일 검토를 명시적으로 선택한다.
5. 확인한 조건으로 후보를 선별하고 개별 선정 이유와 제안 내용을 검토. 회사 공용 공간에 저장된 접촉 이력으로 신규/기존 관계를 구분하며, 아직 미반영한 과거 외부 발송 기록까지 무접촉임을 보장하지 않는다.
6. 일반 신규 크리에이터 TikTok 인증은 심사 승인 후 실제 가입·신청까지 다시 검수. Sandbox 성공은 일반 가입 개방과 다르다.
7. 조건이 준비된 매핑을 활성화하면 단일/다중 발신 검수·초안 저장 가능. 실제 메일은 별도 배치 검수·승인 후 발송 버튼으로 실행. 현재는 모두 draft, 0배치다.
8. 기존 대화는 원래 발신 계정 고정, 수신거부·반송·불만·90일 중복 차단과 일일 잔여량 검수를 유지한다.
