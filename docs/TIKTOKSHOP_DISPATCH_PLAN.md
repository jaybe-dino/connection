# 틱톡샵 대량 발송 관리 시스템 — 기획 v1

> 브랜드가 수십~수백 명의 크리에이터에게 **틱톡샵 인프라를 통해** 제품(샘플)을
> 대량 발송하고, 초대→수락→배송→게시→판매까지 한 화면에서 관리하는 시스템.
> 커넥션 원칙 그대로: **밖으로 나가는 건 전부 게이트**, 모든 전이는 원장 기록.

---

## 1. 왜 틱톡샵으로 발송하나 (문제와 선택)

**지금의 시딩 발송은 수작업이다**: 엑셀로 명단 → 주소 수집(개인정보 부담) →
택배 발송 → 도착 확인 전화 → 게시 여부 수동 추적. 100명이 넘으면 무너진다.

**틱톡샵 타겟 협업(Target Collab) + 무료 샘플로 보내면**:
- **주소를 우리가 안 받는다** — 크리에이터가 틱톡 안에서 수락하며 자기 주소 입력 (PII 부담 소멸)
- **게시가 판매로 이어진다** — 영상에 상품 앵커 자동 부착, 커미션으로 정산
- **어트리뷰션이 공짜** — 누구 영상에서 얼마 팔렸는지 틱톡이 집계
- 대신 **파트너 API 승인(2~4주)이 필요** → 승인 전엔 반자동 모드로 운영(§8)

## 2. 전체 흐름 (퍼널)

```
[대상 선정]        母 DB·셀에서 필터 (국가·등급·팔로워·최근 활동·카테고리)
   ↓
[아리 검증]        4축 판정 재확인 + 협찬 과부하 + 90일 재발송 금지(suppression)
   ↓
[배치 작성]        제품(틱톡샵 상품) · 수량 · 커미션% · 게시 조건 · 기한
   ↓
[게이트 승인]  ◀── 사람. SHIPMENT 게이트: 명단·원가 합계·커미션 노출. 보류=무통지
   ↓
[초대 발송]        틱톡샵 API 타겟 협업 초대 + 무료 샘플 (또는 CSV 반자동)
   ↓
[수락 추적]        수락/거절/만료 — 수락률 낮으면 아리가 재타게팅 제안
   ↓
[배송 추적]        운송장 → 배송중 → 도착 (크리에이터 앱 배송 스텝과 연동)
   ↓
[게시 감지]        기한 내 영상 게시 (#광고 표기 + 상품 앵커) → 검수 파이프라인
   ↓
[성과 집계]        영상별 GMV·커미션 → ROI 카드 → 다음 배치 타게팅에 반영(L2 학습)
```

## 3. 상태 머신

**배치(batch)**: `DRAFT → PENDING_GATE → APPROVED → SENDING → DONE / HELD(보류) / CANCELLED`

**개별 발송(dispatch)**:
```
INVITED ──→ ACCEPTED ──→ SHIPPED ──→ DELIVERED ──→ CONTENT_POSTED ──→ SETTLED
   │            │                        │
   ├→ DECLINED  └→ (7일 무응답) EXPIRED   └→ (기한 초과) NO_CONTENT
   └→ (물류) RETURNED / LOST
```
모든 전이는 원장 이벤트(`SHIPMENT_*`)로 기록 — 분쟁 시 근거.

## 4. 가드레일 (커넥션 철학)

| 규칙 | 내용 |
|---|---|
| 게이트 필수 | 배치 단위 SHIPMENT 게이트. 요약에 **수량·원가 합계·커미션·명단 상위 20명** 표시. 승인=발송, 보류=외부 무통지 |
| 예산 상한 | 브랜드별 월 샘플 예산(원가 기준). 초과 배치는 게이트에 경고 표시 |
| 발송 상한 | 일 배치 1회 · 회당 상한(초기 100명) — 틱톡 스팸 정책 보호 |
| 재발송 금지 | 동일 크리에이터 90일 suppression (기존 아웃리치 억제 목록 재사용) |
| 노쇼 페널티 | NO_CONTENT → 등급 하향 + 이후 배치 자동 제외 + 원장 기록. 2회 → 셀 내 샘플 자격 정지 |
| 수락률 서킷브레이커 | 배치 수락률 30% 미만 → 다음 배치 자동 축소, 아리가 타게팅 원인 분석 리포트 |
| 어뷰징 탐지 | 여러 브랜드에서 샘플만 받고 게시 안 하는 계정 크로스 탐지 → 어드민 큐 |

## 5. 화면 기획

### 브랜드 콘솔 — "발송" 탭 신설
- **배치 목록**: 퍼널 바(초대 120 → 수락 84 → 배송 80 → 게시 61 → 판매 ₩4.2M) + 상태
- **새 배치 위저드**: ① 제품 선택(틱톡샵 상품 연동) → ② 대상 필터(등급·국가·팔로워, 예상 인원 실시간 표시) → ③ 조건(커미션%·게시 기한·필수 해시태그) → ④ 아리 검토(명단 리스크·문구 컴플라이언스) → ⑤ 게이트 제출
- **발송 추적 테이블**: 크리에이터별 상태 · 운송장 · 게시 링크 · GMV. 상태별 필터
- **ROI 카드**: 샘플 원가 대비 GMV·커미션, 게시 전환율 — 대시보드 지표와 연동

### 크리에이터 앱
- 캠페인 카드에 **"샘플 협업 초대"** 유형 추가 — 수락 버튼 → 틱톡 앱으로 딥링크(주소 입력은 틱톡에서)
- 기존 배송 스텝 UI에 연동: 수락 → 배송중 → 도착 → 게시 기한 D-day 리마인더(🔔 알림)
- 게시 완료 시 제출 파이프라인(기존 검수 흐름)으로 자동 연결

### 어드민
- 배치 모니터링: 브랜드별 발송량·수락률·노쇼율
- 물류 이슈 큐: RETURNED/LOST 처리 (SLA 72h)
- 어뷰징 큐: 크로스 브랜드 노쇼 계정 → 조치(경고/정지)

## 7. 아리(에이전트)의 역할

- **타게팅**: 필터 결과에 4축 판정 일괄 적용, 리스크 계정 제외 + 근거를 게이트 요약에 첨부
- **배치 리포트**: 완료 시 "수락률 70% · 게시율 73% · GMV ₩4.2M — B등급 태국 크리에이터가 ROI 최고" 식 요약 → 다음 타게팅 가중치에 반영 (L2 평가 하네스와 동일 구조: 예측→결과→채점)
- **리마인더**: 게시 기한 D-3 크리에이터에게 담당자 대화로 부드러운 리마인드 (주 1회 상한)

## 8. 틱톡샵 연동 — 2단계 전략

### P0 · 반자동 모드 (파트너 승인 전 — **지금 바로 개발 가능**)
1. 시스템이 대상 선정→배치→게이트 승인까지 전부 처리
2. 승인된 배치를 **틱톡 셀러센터 대량 업로드 CSV 형식으로 내보내기**
3. 운영자가 셀러센터에서 업로드(타겟 협업 초대) — 클릭 몇 번
4. 셀러센터에서 결과 CSV 다운로드 → 시스템에 업로드 → 상태 자동 동기화
→ API 없이도 대량 발송의 **선정·승인·추적·성과 관리는 전부 시스템이** 담당

### P1 · 자동 모드 (파트너 승인 후)
- Target Collab 초대·무료샘플 API 직접 호출 (기존 `vendors/adapters.py`의 TikTokShop 어댑터 확장)
- 주문/배송/영상 게시 웹훅 수신 → 상태 자동 전이
- 반자동 모드는 폴백으로 유지 (API 장애 시)

### P2 · 최적화
- 판매 어트리뷰션 대시보드 고도화, 아리 자동 재타게팅, 커미션 정산 자동화(PAYOUT 게이트)

## 9. 지표 (성공 기준)

| 지표 | 목표 |
|---|---|
| 초대 수락률 | 50%↑ (콜드 대비 셀 멤버 우선 시 70%↑) |
| 발송→게시 전환율 | 70%↑ (기한 14일 기준) |
| 샘플 ROI | GMV ÷ 샘플 원가 3배↑ |
| 노쇼율 | 15%↓ (페널티 정착 후 10%↓) |
| 운영 공수 | 100명 발송 기준 운영자 30분 이내 (반자동 모드) |

## 10. 개발 순서 제안

1. **P0-1**: 마이그레이션 005 + 배치/발송 엔진(상태 머신·가드레일) + SHIPMENT 게이트 연동 + 테스트
2. **P0-2**: CSV 내보내기/가져오기 (셀러센터 형식) + 러너에 배치 잡 등록
3. **P0-3**: 콘솔 "발송" 탭 UI (배치 위저드·추적 테이블·ROI 카드) + 크리에이터 앱 초대 카드
4. **P0-4**: 어드민 물류·어뷰징 큐 + E2E 검증
5. **P1**: 틱톡샵 파트너 승인 나오면 API 어댑터 연결 (승인 신청은 사장님 체크리스트 B-6번 — 지금 접수해두면 P0 개발과 병행됨)
