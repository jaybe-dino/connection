# theprlist UI 디자인 가이드 (2026-09-30)

방향: **"브랜드의 크리에이터 관계를 쌓는 PR 워크스페이스"** — 제품과
캠페인이 주인공인 밝고 정돈된 에디토리얼 스타일 + 업무 도구의 명확한
상태·일관된 탐색. 참고 원칙은 Linear 2026 UI refresh·Vercel Geist의
"일관된 헤더 / 조용한 탐색 / 정보 위계"이며 외형을 복제하지 않는다.
금지: 검정 배경 기본, 네온 그라데이션, 과도한 카드·그림자, 이모지 버튼.

## 0. 개선 전 문제 (2026-09-30 기준 실화면 진단)

| 표면 | 문제 |
|---|---|
| 콘솔 | 페이지마다 h1 크기·행동 위치 제각각, 홈이 마케팅 히어로(다음 할 일 없음), 메일 페이지가 연결→작성→발송 위계 없이 카드 나열, 배경/포인트 색이 베이지·녹색 혼재로 "업무 도구" 인상 약함, 버튼 높이 34px대(터치 44px 미달), focus 표시 없음 |
| 크리에이터 | 한 페이지에 브랜드/캠페인/협업/커뮤니티가 전부 세로 나열 — 모바일에서 목적지 탐색 불가, 브랜드 로고가 상단 정체성으로 안 보임, 단계별 "다음 행동" 안내 없음 |
| 랜딩 | 메시지가 관계·워크스페이스보다 '연결' 추상어 중심, 흐름 시각화가 학습→발송 2단계뿐(후보 추천·커뮤니티·청구 부재), 카드 필수 아님·크리에이터 참여 방식 설명 없음 |
| 가입 | 3단계 구획은 있으나 오류가 필드별로만 뜨고 제출 요약 없음, 분석 근거가 항상 펼쳐짐 |
| 관리자 | (이전 사이클에서 모바일 압착 해결) 밀도·상태/행동 구분은 유지, 계산서 오인 문구 없음 확인 |
| 공통 | 토큰 없음(색 하드코딩 산재), reduced-motion 미지원, 성공/실패가 색만으로 구분되는 곳 존재 |

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | #F7F8FA | 페이지 배경 |
| `--surface` | #FFFFFF | 카드·패널 |
| `--ink` | #18202B | 본문 |
| `--ink-2` | #566274 | 보조 문자 |
| `--line` | #DCE2E8 | 테두리·구분선 |

- #566274 on #FFFFFF = 6.2:1 ✓ · on #F7F8FA = 5.8:1 ✓
- #FFFFFF on #155E57(버튼) = 7.5:1 ✓ · #155E57 on #E7F1EE = 6.3:1 ✓

## 2. 컴포넌트 규칙

- **버튼**: 기본(`.btn` — accent 배경·흰 글자) / 보조(`.btn.line` — 흰
  배경·line 테두리·ink 글자) / 위험(`.btn.danger` — #A2372B). 한 화면
  구획에 기본 버튼은 1개, 위치는 구획의 좌하(폼) 또는 우상(목록 행동)
  고정. `.cbt`(인라인 소형)는 보조, `.cbt.no`는 조용한 보조.
- **입력**: 레이블 항상 표시(placeholder만으로 대체 금지), 44px,
  focus-visible에 2px accent 외곽선. 오류는 필드 밑 문구+상단 요약.
- **카드 `.cc`**: surface + 1px line + radius 12, 그림자 없음(호버 시
  테두리만 진하게). 중첩 카드 금지.
- **상태 문구**: `✓ 완료` / `! 확인 필요` / `× 실패 — 재시도` 패턴,
  role=status/alert 유지.
- **헤더**: 모든 콘솔 페이지 동일 — 로고 · 현재 브랜드(로고+이름) ·
  탐색 · (관리자면) 브랜드 전환. 페이지는 h1 제목 + 한 줄 설명 +
  주요 행동으로 시작.

## 3. 화면별 기준

- **랜딩**: 첫 메시지 "우리 브랜드와 맞는 크리에이터를 찾고, 관계를
  이어가세요." 주 CTA `브랜드 가입 신청` 1개 + 보조 `진행 방식 보기`.
  흐름 4단계(브랜드·제품 학습 → 후보 추천·초대 → PR 리스트 커뮤니티 →
  협업·월별 청구) 시각화. 요금: 검증 가입 1명당 5,000원 VAT 포함 ·
  월별 합산 · 고정 구독료 없음 · **카드 등록 필수 아님**. 가짜 고객
  로고/성과 수치/자동발송·전달률 보장 문구 금지. "크리에이터는 브랜드
  전용 공간(PR 리스트)으로 초대받아 참여" 설명 포함.
- **가입**: 3단계 구획(브랜드 정보 / 브랜드·제품 이해 / 신청 확인),
  레이블 상시, 예시·사용 가능/불가 즉시 검증, 분석 중/실패·재시도/
  직접 입력 대체 상태 명확, 분석 결과의 출처·근거는 접기(details),
  "모델 재훈련 아님" 명시, 오류 시 필드+상단 요약(비밀번호 등 반향
  금지), 단계 이동/오류에 입력 보존.
- **콘솔**: 동일 헤더(로고·브랜드 칩·메뉴), 홈은 실제 저장 데이터
  기반 "다음 할 일"(불러오는 중/0건/실패를 구분, 실패를 0으로 위장
  금지), 브랜드 전환 상태 상시 노출. 메뉴: 홈 / 브랜드 학습 /
  제품·캠페인 / 커뮤니티·DM / 아웃리치·인박스 / 월별 청구(기존 구조
  유지, 정보 구조 정리).
- **제품·캠페인**: 프로필 폼은 요약→"편집" 펼침, 버전·마지막 저장
  표시. 후보 카드에 국가·플랫폼·근거·이메일 검증 상태·선택 체크가
  한눈에, 선택 개수+초안 CTA 상시 노출. AI 모드/키워드 폴백 구분 유지.
- **아웃리치·인박스**: 위계 = ① 발신 브랜드·Gmail 연결 상태(주소·
  권한·재연결·점진 발송 한도·대기) ② 작성(초안) ③ 검토·발송(내역)
  ④ 받은 답장. "초안 저장"과 "발송"을 시각·문구로 구분. 웜업은
  "점진 발송 한도"로 설명, 상호회신·스팸 회피 보장 문구 금지.
  인박스는 목록→대화 위계, 번역 중/원문/재시도 구분.
- **크리에이터**: 모바일 우선. 상단 = 참여 브랜드 로고·이름 + 작은
  theprlist. 탭 탐색: 브랜드 / 캠페인 / 내 협업 / 커뮤니티·메시지.
  초대→로그인→합류→지원→선정→조건 확인→샘플 배송→콘텐츠·Spark 제출→
  완료를 단계별 "다음 행동"으로 안내. 내부 DB명·개발 용어 숨김,
  커뮤니티(라운지)와 DM 구분, 원문·번역·작성 언어 표시 유지.
- **관리자**: 업무용 중립 밀도, 375/390에서 사이드바가 본문 압착 금지
  (상단 랩 메뉴), 상태/처리 행동/오류·재시도 구분, 청구 관련 표기는
  "계산서 준비 안내"까지만.
