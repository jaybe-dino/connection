# 커뮤니티·모집·메일 UX 정리 (2026-10-19)

- 대화 언어는 채팅 헤더 안의 작은 선택 상자로 이동. 긴 설명은 기본 접힌 도움말로 제공.
- 설정 화면에서도 같은 언어 선택 컴포넌트 사용. 기존 기기별 언어 저장과 작성 중 메시지 보존 유지.
- 커뮤니티·DM·캠페인·설정의 기본 버튼/입력창은 44px 이상, 10px 모서리, 같은 포커스 표시 적용.
- 모바일 검색은 별도 줄로 배치하여 언어 선택/검색 버튼 축소 방지. 브랜드방/채널/담당자 DM 구조 유지.
- 모집 관리자와 새 크리에이터 메일 CRM의 선택 색상·카드·입력 방식 통일. 모바일 모집 메뉴는 두 열로 줄바꿈.
- 공개 화면 배포 자산 일치와 로컬 합성 데이터 화면 검수. 실계정 로그인 후 대화 발송은 이번 검수에서 하지 않음.
- CRM 사용 및 안전 경계: CREATOR_EMAIL_CRM_20261019.md 참조.

## 브랜드 채널·모바일 보완
- 브랜드 선택은 독립된 레일/모바일 선택 영역. 채널 사이드바에는 선택 브랜드의 잡담·촬영 팁·공지와 해당 브랜드 담당자 DM만 표시.
- 다른 브랜드 대화와 채널은 같은 목록으로 합치지 않음. 기존 서버 멤버십 검사, 셀별 조회·초안·이전 요청 응답 무시 기능 유지.
- 모바일 상단의 중복 검색 버튼 제거. 채널 검색은 접힌 버튼에서 필요할 때 펼침.
- 채널 헤더의 긴 설명은 브랜드·멤버 정보로 축소. 언어 선택과 검색을 한 줄로 배치.
- 메시지 입력과 보내기를 같은 줄에 배치. 입력 글자는 16px로 유지해 모바일 입력 확대 방지, 버튼 최소 44px 유지.
- 실제 모바일 키보드/운영 실계정 대화 발송은 이번 검수 범위 밖. 로컬 합성 데이터와 실제 렌더러로 375/390px 레이아웃 검수.
