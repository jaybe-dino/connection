# 커뮤니티·모집·메일 UX 정리 (2026-10-19)

- 대화 언어는 채팅 헤더 안의 작은 선택 상자로 이동. 긴 설명은 기본 접힌 도움말로 제공.
- 설정 화면에서도 같은 언어 선택 컴포넌트 사용. 기존 기기별 언어 저장과 작성 중 메시지 보존 유지.
- 커뮤니티·DM·캠페인·설정의 기본 버튼/입력창은 44px 이상, 10px 모서리, 같은 포커스 표시 적용.
- 모바일 검색은 별도 줄로 배치하여 언어 선택/검색 버튼 축소 방지. 브랜드방/채널/담당자 DM 구조 유지.
- 모집 관리자와 새 크리에이터 메일 CRM의 선택 색상·카드·입력 방식 통일. 모바일 모집 메뉴는 두 열로 줄바꿈.
- 공개 화면 배포 자산 일치와 로컬 합성 데이터 화면 검수. 실계정 로그인 후 대화 발송은 이번 검수에서 하지 않음.
