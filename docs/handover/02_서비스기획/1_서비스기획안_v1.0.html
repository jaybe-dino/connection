01

서비스 정의

문제. K-뷰티 브랜드의 해외 크리에이터 운영은 사람이 하는 노가다다 — 후보를 찾고, DM을 돌리고, 커뮤니티에 공고를 올리고, 지원자를 거르고, 배송하고, 검수하고, 정산한다. 대행사는 비싸고 데이터가 남지 않으며, 마켓플레이스는 거래만 중개하고 관계와 결과를 남기지 않는다.

해법. 브랜드마다 전담 에이전트 아리가 이 전 과정을 운영한다. 크리에이터는 커넥션 계정 하나(패스)로 여러 브랜드의 커뮤니티(셀)에 소속되고, 브랜드는 콘솔에서 아리와 대화하며 결정만 내린다. 밖으로 나가는 모든 행동(발송·게시·정산·개인정보)은 게이트를 거쳐 사람이 승인한다.

차별점 4가지

축내용
에이전트 = 담당자기능 목록이 아니라 목표·KPI·판단 규칙·실패 조건을 가진 담당자 8명 체제. 모든 판단은 30일 뒤 결과로 채점되고 가중치가 갱신된다 — 성적표가 해자.
죽지 않는 방셀에는 조급함 장치(읽음·타이핑·@everyone·출석 보상)가 없다. 매일 마중물, 주간 멤버 콘텐츠 피드, 침묵 감지가 방을 살린다. 인원 상한 없음 — 발화 밀도로 건강을 판단.
검증된 DB가입은 틱톡/인스타 OAuth로만. 수기 행이 없어 가짜·중복이 구조적으로 안 생기고, 필드마다 보유 근거(어느 동의)와 파기 예약이 붙는다.
전면 자동 번역크리에이터는 무조건 자기 언어(IP 초기값)로 본다 — 셀 대화·캠페인·담당자 1:1 전부. 원문은 칩 한 번. 브랜드는 본국어 중심으로 본다.
02

사용자와 핵심 여정

브랜드 담당자 (마케팅 리드 · 대표)

가입 · 사업자 확인→슬러그 예약→플랜 선택→ 아리 학습 (사이트 + 5문항)→콘솔 브리핑→매일: 게이트 승인 + 아리 대화

가입이 곧 아리 세팅이다. 사이트 링크를 넣으면 아리가 제품·리뷰·SNS를 읽어 브랜드 프로필 초안을 만들고, 사이트가 말해주지 않는 5문항(브랜드 한 문장 · 맞는 크리에이터像 · 금지어 · 샘플 기준 · 말투)을 묻는다. 학습 없이는 모집을 시작할 수 없다. 이후 브랜드의 일상은 하루 10분 — 승인함의 결정과 아리와의 대화가 전부다.

크리에이터 (태국 · 미국 · 베트남 등)

초대 링크 / 인바운드→틱톡·인스타 OAuth 가입→브랜드 동의 · 자격 확인→ 셀 생활→캠페인 지원 · 1:1→제출 · 검수 · 정산

계정은 한 번만 만든다. 두 번째 브랜드부터는 브랜드별 동의만 새로 받고 바로 입장(재가입 없음). 셀 안에서는 다른 크리에이터와 대화하고 서로의 콘텐츠 예시를 보고, 담당자 탭에서 셀별 담당자와 1:1로 이야기한다. 주소·연락처·피부 타입·계좌는 본인이 수정하고 브랜드 DB에 실시간 반영된다.

4.1 계정 · 가입

항목크리에이터브랜드
가입 수단틱톡 또는 인스타 OAuth 필수. 이메일 가입 없음. Google·Discord는 가입 후 보조 로그인만. 사업자등록번호 국세청 조회 + 담당자 메일 인증.
필수 동의본인 확인 · 약관 · 국외 이전 (3종) + 선택: 교차 브랜드 추천. append-only 기록. 약관 + DPA(개인정보 처리 위탁) + 데이터 이용 원칙(과금 제외≠차단 · 열람·이의 · 철회 전파).

소스 3개 — ① 사이트 학습(제품 상세·리뷰·인스타 90일 → 포지셔닝 / 주력 제품 / 성분 키워드 / 가격대 / 고객의 언어 / 톤, 각 항목에 출처 표기 + 확인·수정 단계) · ② 온보딩 5문항 · ③ 운영 피드백(반려·추가 사유 축적). 산출은 버전 관리되는 브랜드 프로필 v. 소비처 4곳 — 4축 판정 적합도, 초대문·공고 개인화(복붙 9% vs 개인화 47%), 채널 우선순위, 금지어 필터.

4.5 캠페인 시스템

보상 유형 3종 — 유가(고정 보상 · 검수 통과 시 지급) / 무가(제품 제공만 · 게시 의무 없음) / 어필리에이트(판매액 % · 전용 링크). 필수 필드: 이름 · 제품 · 이미지 · USP(브랜드 프로필의 '고객의 언어'에서 선택 가능) · 구체 조건(길이·노출·표기) · 정원 · 마감.

등록→자동 번역 (th·en·vi)→동시 게시: 캠페인 목록 + 셀 공지→ 지원→1:1 (셀 담당자 탭 · 자동 번역)→선정→배송(PII 게이트)→ 제출 · 자동 체크→검수 통과→정산(게이트)

크리에이터에게 캠페인은 무조건 자기 언어로 뜬다(원문은 칩). 선정 전 1:1은 셀별 담당자 대화에서 이어지며 번역이 양방향 관리된다(브랜드 KO↔크리에이터 모국어). 지원자 화면: 등급 · 매치 점수 · 1:1 · 선정 버튼.

4.6 크리에이터 DB

라이프사이클 세그먼트(전체/활성/신규/초대됨/휴면/이탈/과금 제외) + 검색 + 레코드 카드 (검증 계정 · 여정 타임라인 · 보유 필드와 근거 · 아리 메모). 위생 스트립: 중복 병합 · 본인 수정 실시간 반영 · SNS 90일 재검증 · 필드 파기 예약. CSV 내보내기는 연락처 포함 시 PII 게이트. 본인 수정(주소 등)은 원장 PROFILE_UPDATED로 기록되고 즉시 반영.

4.9 크로스 노출 정책 (중요)

셀 컨텍스트는 브랜드 단독 세계 — 다른 브랜드의 존재가 화면에 없다. 탐색 피드·셀 랭킹은 만들지 않는다. 이동 경로는 둘뿐: 초대 링크(크리에이터의 선택), 옵트인 추천(동의자에게만 · 담당자 대화로만 · 월 1회 이하 · 같은 카테고리 브랜드 배제). 브랜드 영업 프레임은 "나가는 문"이 아니라 "다른 브랜드가 검증한 크리에이터가 마찰 없이 들어오는 문". Enterprise에는 추천 전면 차단(배타권) 옵션 — 기본값은 아님.

05

데이터 · 신뢰 (4층 기술 스택)

층내용
L1 결과 파이프라인초대→수락→샘플→게시→검수→90일 잔존이 한 사람에게 귀속되는 이벤트 스키마. 귀속 규칙(최초 접점 · 7일 윈도) · 아이덴티티 그래프(동의 범위 내).
L2 평가 하네스아리의 모든 예측이 30일 뒤 자동 채점(브라이어 점수) → 가중치 갱신이 원장에 남음.
L3 규범 메모리커뮤니티별 통한 문구·잘린 문구·밴 사례, 버전 관리 + 근거 링크. 새 브랜드는 첫날부터 상속.
L4 신뢰 인프라판단 원장(append-only) · 크리에이터 열람·이의 제기(복구도 기록) · 동의 철회 즉시 전파(참조 절단 + 캐시 파기).

투자하지 않는 것 — 자체 LLM·파인튜닝(라벨 1만 건 전), 스크래핑(공식 API·인바운드·붙여넣기로 충분), 범용 CRM.

크리에이터 입장

빠진 것왜 문제인가 · 제안우선
알림 센터 · 푸시 설정선정·배송 도착·검수 결과·정산·마감 D-3 — 지금은 앱을 열어야만 안다. PWA 푸시는 선언만 있고 알림함·채널별 on/off가 없다. 알림함 탭 + 유형별 설정 필요.P0
배송 추적크리에이터가 담당자에게 제일 많이 묻는 게 "샘플 언제 와요?"다. 캠페인 화면에 송장 번호 + 배송 상태 스텝이 있으면 1:1 문의의 절반이 사라진다.P0
정산 수단 온보딩 · 인출계좌 필드는 있지만 PingPong 연결 플로우, 최소 인출액, 수수료, 실패 시 재시도가 없다. 돈 받는 경험이 불투명하면 잔존이 무너진다.P0
신고 · 차단 (안전)셀은 여러 명이 모이는 방인데 괴롭힘·스팸 신고 장치가 전무하다. 메시지 길게 눌러 신고 → 아리 1차 분류 → 운영자 검토. 이거 없이 커뮤니티 서비스를 열면 안 된다.P0
언어 수동 변경IP 자동은 초기값일 뿐 — 여행 중이거나 다국어 사용자는 바꿔야 한다. 내 패스에 언어 선택 한 줄.P0
세금 · 소득 문서국경 넘는 지급이라 연간 소득 요약, 원천징수 정보, 인보이스가 필요하다. 정산 탭에 연간 문서 다운로드.P1
계정 삭제 · 데이터 내보내기철회 전파는 설계했지만 본인 주도 탈퇴 + 내 데이터 다운로드(태국 PDPA·GDPR 대응) UI가 없다.P1

브랜드 입장

빠진 것왜 문제인가 · 제안우선
