크리에이터 앱 PWA · 모바일

connection.app/{brand}
  • 온보딩✓
    • 웰컴 — 구조 설명 · 브랜드 URL 원칙 안내
    • 커넥션 가입 — 필수 동의 3 + 선택 1 · 틱톡/인스타 OAuth 필수 (이메일 가입 없음)
    • 브랜드 셀 합류 — 브랜드별 동의 2 · 자격 확인 · 셀 입장 두 번째 브랜드부터 재가입 없음
  • ① 셀✓TR 헤더: ↗ 공유(링크 복사) · 언어 칩
    • # 잡담 — 멤버 대화(원문 칩) · 아리 마중물 · 콘텐츠 예시 카드 · 주간 피드
    • # 촬영 팁 — 큐레이션 채널
    • ◎ 공지 (읽기 전용) — 캠페인 카드(이미지·조건·USP 번역) → 캠페인 탭
    • P0 신고 · 차단 — 메시지 길게 눌러 신고 → 아리 분류 → 운영자
  • ② 담당자✓TR
    • 셀 스위처 — "GLOWLAB 담당 / AURA 담당" · 대화는 셀끼리 섞이지 않음
    • 1:1 스레드 — 아리 운영 대화 + 캠페인 선정 대화(브랜드 담당자 참여) · 실입력
  • ③ 캠페인✓TR
    • 목록 — 이미지 · 조건 배지(유가/무가/어필리에이트) · USP 칩 · 무조건 내 언어(KO 원문 칩)
    • 지원 → 상태 — 지원 완료 · 선정됨 · 배송 준비 ↔ 콘솔 지원자 탭
    • P0 배송 추적 — 송장 · 상태 스텝 1:1 문의 절반 제거
  • ④ 제출✓
    • 업로드/링크 붙여넣기 — 자동 체크(길이·노출·#ad) · 원클릭 보정 · 검수 상태
  • ⑤ 정산✓
    • 지급 예정/완료 — 캠페인 보상 · 셀별 분리 정산
    • P0 정산 수단 온보딩 — PingPong 연결 · 수수료 · 인출 · 실패 재시도
    • P1 세금 · 소득 문서 — 연간 요약 · 인보이스
  • ⑥ 내 패스✓
    • 프로필 — SNS 검증 배지 · 완주율 · 등급 기록은 본인 소유, 브랜드 바뀌어도 따라감
    • 내 정보 관리 — 주소·연락처·피부 타입·계좌 본인 수정 → 콘솔 DB 실시간
    • 동의 설정 — 교차 추천 on/off(동종 카테고리 배제) · 초대 링크 입장(셀 탐색 없음)
    • P0 언어 수동 변경 · P1 탈퇴 · 데이터 내보내기
  • 알림함P0 선정·배송·검수·정산·마감 D-3 · 유형별 푸시 설정 · PWA 설치 배너 ✓

공통 시스템 레이어 화면 뒤에서 전 표면을 받치는 것

인증 · 패스
모든 링크 → 패스 로그인 → 원위치 리다이렉트. 계정 1 · 브랜드별 멤버십 N.
번역 레이어 TR
시청자 언어 자동 표시 + 원문 칩. 캠페인은 게시 시 일괄 생성 · 용어집 · 미리보기.
게이트 엔진 GATE
PII · PAYOUT · OUTBOUND · PUBLISH — 자율 등급과 무관하게 사람이 승인.
원장
append-only · 판단 근거 · 채점 · 동의 · 프로필 수정 이력 전부 기록.
브랜드 프로필
사이트 학습 + 문답 + 운영 피드백 → 판정·문구·채널·금지어의 뿌리. 버전 관리.
평가 하네스
모든 예측 30일 채점 → 가중치 갱신. L2 승격 기준 = 브라이어 점수.
알림 시스템 P0
크리에이터 알림함·푸시 + 브랜드 승인 대기 외부 알림. 유형별 설정.
운영자 콘솔 P1
신고 처리 · 분쟁 심판 · 어뷰징 · 아리 품질 모니터링 (커넥션 내부).
