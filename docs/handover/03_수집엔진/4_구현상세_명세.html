3.2 그래프 확장 파라미터

파라미터기본값의미
seed_pages_per_tag50해시태그당 긁는 페이지

3.3 수렴 판정 로직

window = ring_buffer(10_000) on each account processed: window.push(is_new) new_rate = sum(window) / len(window) if new_rate < 0.03: streak += 1 else: streak = 0 if streak >= 3_batches: mark_converged(country, category) # 사실상 전수
폭주 방어 — 그래프 확장은 지수적으로 커질 수 있다. expand_fanout_cap과 국가·카테고리별 일일 discover 예산(예: VN·선케어 하루 5만 계정)으로 상한을 건다. 예산 소진 시 다음 날로 이월.

Score 공식

7.1 영향력 스코어 (0~100)

influence = 100 * sigmoid( 0.30 * z(log(followers)) + 0.28 * z(engagement_rate) + 0.18 * z(avg_views / followers) # 도달 효율 + 0.14 * z(post_freq_30d) + 0.10 * z(gmv_signal) # 커머스(있으면) - penalty ) penalty = 0.5*step_growth_flag # 계단형 급증(가짜) + 0.3*(sponsor_ratio_90d > 0.4) # 협찬 과다 + 0.4*(days_since_last_post > 45) # 휴면

7.2 접촉 우선순위 스코어

contact = influence + 20*(email_status=='valid') + 10*has(whatsapp|zalo|line) + 15*category_match(brand_profile) # 브랜드 붙었을 때

처리량 · 비용 워크드 예제 (100만 계정)

한 국가 파드가 母 DB 100만을 채우는 단계별 볼륨·비용(설계 기준값, 협상 전 공개 단가).

단계볼륨단가비용(개략)
L2 라이선스 스냅샷50만 계정계약(대량)협상 · fetch 스킵
Discover(해시태그·키워드)영상 500만 조회$1/1K~$5,000
Fetch 프로필(신규 50만)50만 req$0.99/1K~$495
그래프 확장(댓글·추천)1,500만 호출$1/1K~$15,000
link-in-bio 크롤(상위 40만)40만 크롤$2/1K~$800
이메일 DB 조인(상위 25만)25만 조회크레딧중간 비중
이메일 검증(30만)30만~$0.5/1K~$150
프록시·인프라·큐—월 고정+가변월 운영비
API 직접비 합계(개략)~$21,000~35,000 + 라이선스
계정당 원가 — 위 합계 / 100만 ≈ 25~50원(API 직접비). 라이선스·인프라 포함해도 목표 30~120원 안. 핵심 지렛대는 ①L2로 50만의 fetch·discover를 통째로 생략, ②그래프가 최대 비용이니 fanout_cap·일일예산으로 조인다.
비용 급증 포인트 — 그래프 확장(§8 최대 항목)이 통제 안 되면 수백만 호출로 폭주한다. 반드시 수렴 판정으로 조기 종료 + 국가·카테고리 일일 예산 상한. 이게 "비용 들어도 최대한"을 낭비 없이 실현하는 방법.
