1. 연결할 자산

14개 도메인은 관리대장에 등록. 운영 용도를 정한 도메인부터 인증. SES는 한 AWS 계정·리전의 공통 할당량을 공유. Workspace 조직은 가능하면 기존 회사 조직 재사용, 회신 담당 실제 사용자와 서비스별 별칭을 구분. 발신 도메인의 MX 수신과 SES MAIL FROM의 bounce 하위 도메인 MX는 별도.

기존 Theprlist routes_gmail.py의 2→20통 단계 한도는 유지. routes_senders.py의 데모 인증과 예시 SendGrid DNS는 실서비스 상태로 사용하지 않음. 새 SES 도메인 어댑터가 발급값·실제 검증 상태를 저장. Glovek 시드 전송 제한을 해제하지 않음.

4. 실행 worker의 필수 순서

  1. 트랜잭션으로 dispatch와 quota reservation을 선점. global pause·brand pause·batch pause를 확인.
  2. 승인 만료/취소/정확한 대상·문안·발신자·시간·수량 범위를 재확인. 실행자가 새 대상을 임의로 추가할 수 없음.
  3. 동의 범위·최초 접촉·공통 제외·기존 예약·실제 도메인 인증·계정 중지를 재확인. 수신거부는 배치 생성 뒤에도 적용.
  4. quota pool의 rolling 24시간과 초당 rate limit을 적용. 승인된 최대 수량·비용에서 차감. configuration set을 항상 명시.
  5. SES 1수신자 1요청. Message-ID와 dispatch_id/batch_id/sender_id 태그를 저장. 개인별 상세 내용을 로그에 불필요하게 출력하지 않음.
  6. 명확한 접수 실패만 규정된 재시도. 타임아웃/접수 결과 불명은 UNKNOWN 및 배치 보류, 자동 재발송 금지. SES SendEmail에 자체 exactly-once 보장이 있다고 가정하지 않음.
  7. SNS/SQS 소비자가 신뢰된 topic/queue, event id/message id, 재처리 중복을 검증. 이벤트 역순 수신에 상태를 퇴행시키지 않음.
  8. 영구 반송·불만은 공통 제외에 반영. 일시 지연·일시 반송은 별도로 처리. complaint 발생 시 해당 캠페인을 보류해 원인을 검토.

5. 규모 확대와 인력

SES 계정·리전 한도 요청안 20,000수신자/24시간·2수신자/초. 신규 목표 10,000명/일, 남은 용량은 후속 관계 안내용 계획 여유. 승인되지 않으면 낮은 한도를 그대로 적용. 8시간 신규 운영 평균 0.347명/초.

초기 검수 배치는 단순한 날짜 기반 곡선 대신 인증·목록 품질·거부 처리·배달·회신 결과를 근거로 사용자 승인 수량을 늘림. 일반 신규 대상 batch approval과 회사 소유 시험 수신자 발송도 각각 승인된 범위에서 실행.

회신 처리 계획: 실제 관측값이 나오기 전 2~8% 스트레스 시나리오로 200~800회신/일·건당 3분 10~40시간/일. 유료 협업 협의·물류·콘텐츠 업무는 추가. 실적 예측으로 사용하지 않음.

6. 운영 지표

주간/월간 최초 시도 고유 인원, SES 접수 고유 인원, 수신 서버 배달 고유 인원, 반송/불만/거부, 회신, 신청, 참여 확정, 출고, 수령, 게시, 주문을 분리. 캠페인 참가 건수와 회사 전체 고유 인원 독립. SMTP/SES 수신 서버 접수는 받은편지함 도착 지표가 아님. 과거 차단 이력과 BCC 발송 보고는 배달 증거로 쓰지 않음.

7. 배포·승인·복구

기존 설정 읽기 → 비밀값 제외 백업 → 변경 미리보기/CloudFormation Change Set → 발송 비활성 상태 설정 → 인증 검수 → 사용자 시험 발송 승인 → 실제 수신/회신/거부/피드백 인수 → 캠페인 사용자 승인 → 예약 실행. 실제 비용·권한·DNS 적용 전 확정 계정과 범위를 확인.

복구: worker 중지 → configuration set 발송 비활성화 → queue/원장 보존 → 변경한 DNS만 복구 → UNKNOWN과 Message-ID 대조 → 재개 승인. Retain 자원은 스택 삭제 이후에도 남아 비용 가능, 삭제 목록 별도 관리. Git 기준점 mail-launch-base-20261013 = ec81eab.
