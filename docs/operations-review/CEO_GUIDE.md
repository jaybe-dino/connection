# 대표 검토·실행 준비 가이드

**현재 단계:** 격리 로컬 개발과 자체 QA. 외부 연락·운영 반입·배포·실청구 없음.

**근거:** e1eeeed 코드의 패스·브랜드 셀·신규 검증 가입5,000원 월 과금과10/6~10/8 운영 자료. 원격 최신, 실계정 상태, 현재 계약·물류는 미확인.

**추천안:** Theprlist를 관계/브랜드/과금의 중심으로 유지하고, 적합성 선별·투명한 조건·통합 회신·재참여를 먼저 연결한다. Glovek의 시드 제한을 해제하지 않는다. 첫 성과는 발송량이 아니라 확정→수령→게시 전환과 단위 원가로 검증한다.

## 45분 검토

1. `tools/operations-review/index.html`을 브라우저로 열어 구조·BM 확인(10분). 월3만 인정 단계와 현재5천원 모델 유지/수정/보류를 기록한다.
2. 브랜드 수요 탭에서 첫 브랜드·상품·국가 선택(10분). RETURNU는 기존17명의 흐름 근거 확인에 유리하지만 물류·납기 확인 전 모집 실행 대상으로 확정하지 않는다. FAU는 계약 목표 충돌부터 해결한다.
3. 규모·손익 탭에서 유지 인원, 실측 전환율, 검증된 연락 가능 고유 공급, 회신/출고/검수 용량, 회사 부담 원가 입력(10분). 모르는 값은 숫자를 만들어 넣지 않는다.
4. 개발·QA와 `QA_REPORT.md`, `ROLLBACK.md` 확인(10분). 이번 개발은 증빙·상태·CSV 안전성/인증·검토실이다. 전사 CRM·다계정 실발송·주문 대사는 미구현이다.
5. 대표 검토 탭에 결정을 저장하고 JSON으로 내려받기(5분). 운영 승인이나 외부 연락은 발생하지 않는다.

## 검토 후 역할별 해야 할 일 — 확정 지시가 아닌 제안

- 이성경 팀장 연결: 목표/마감/경로 귀속 충돌을 기존 자료에서 먼저 해결하고 남은 질문만 모은다. 새로운 전체 보고를 다시 요구하지 않는다.
- 캠페인 실무: 17명 등 기존 참가자의 상태·담당·다음 행동을 맞추고 조건별 회신 분류 기준을 검토한다.
- 물류 담당: 실제 입고·SKU·주소 수집·추적·수령·분실 처리와 주간 처리량을 확인한다.
- 콘텐츠 담당: 게시 URL, 주장의 근거, 검수 SLA, 수정 횟수, 사용권을 확인한다.
- 재무: 가입 사용량·청구·입금·환불과 회사 부담 원가를 분리한다.
- 개발: 검토 결정에 따라 데이터 계약→거부/중복→회신 귀속→OSMU 순서로 구현한다. 배포 전에 스테이징에서 기존 READY 이전 기록과 과금 회귀를 확인한다.

누구에게도 이 문서의 업무를 전송하거나 확정 배정하지 않았다. 계약 확인·플랫폼 정책·실계정 접근이 필요한 단계는 별도 확인 사항이다.
