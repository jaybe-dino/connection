# 개선 번호 검토 시안 (2026-10-25)

운영 반영 전 검토용 **정적 UI 제안물**입니다. 제품 코드·서버·운영 데이터는 바꾸지 않았고, 이 폴더 밖 파일도 수정하지 않았습니다.
체크와 ‘요청 문장 복사’는 시안 선택일 뿐입니다. 사용자가 채팅에 요청 문장을 직접 붙여야만 제품 반영을 검토합니다.

## 실행
- 로컬 서버: `python3 -m http.server 8765` 실행 후 `http://127.0.0.1:8765/` 접속 (이 폴더에서 실행)
- `index.html`을 직접 열어도(file://) 동작합니다. 데이터가 `app.js`에 같이 들어 있기 때문입니다.
- 외부 네트워크 요청, 프레임워크, CDN은 쓰지 않습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 검토용 바, 무대, 설명 레이어, 선택 목록, 제품 레이어 껍데기 |
| `styles.css` | 플럼(#302037/#695177) 기반 밝은 본문. 검토 도구는 짙은 회색과 주황 점선으로 제품 UI와 구분 |
| `app.js` | 렌더링과 동작 전부. 브랜드 8화면, 크리에이터 6화면과 레이어 7개, 관리자 7화면 |
| `improvements.json` | 기존 40개 원문(번호·ID·역할·제목·동작·선행) + `easyName`(쉬운 이름), `pain`(현재 어려움), `proposal`(시안 위치) |
| `coverage.json` | ID별 역할·시안 화면·hotspot ID·현재 캡처 위치(%)와 캡처 크기 |
| `tools/embed_data.py` | 두 JSON을 `app.js` 데이터 마커 사이에 다시 넣는 스크립트. JSON을 고친 뒤 실행 |
| `assets/` | 현재 화면 캡처를 넣는 곳 (비어 있음) |

## 현재 UI 캡처 넣기
`assets/current-brand.png`(633×917), `assets/current-creator.png`(390×844), `assets/current-admin.png`(633×917)를 넣으면 됩니다.
- 이미지는 원래 비율을 지키고, 원본 폭보다 크게 늘리지 않습니다. 다른 크기(예: 1440×1000)를 넣어도 실제 크기를 따릅니다.
- 파일이 없으면 가짜 화면 대신 ‘캡처 없음’ 안내를 보여 줍니다.
- 캡처에 올린 번호: 브랜드 홈 B01·B02 / 크리에이터 내 협업 C04·C06·C10 / 관리자 검수 현황 A03·X04.
  **좌표는 임시값입니다.** 캡처를 넣은 뒤 위치를 확인하고 `coverage.json`의 `captures.*.hotspots`(x%, y%)를 고친 다음 `python3 tools/embed_data.py`를 실행하세요.
- 캡처에 없는 개선은 ‘다른 화면 개선’ 목록과 ‘공통 개선’ 목록에서 해당 시안으로 이어집니다.

## 동작 요약
- 검토용 바: 역할 전환 / 현재 UI+개선번호 ↔ 개선 후 시안 / 번호 보이기 / 선택한 개선(n) / “실제 반영 아님” 고정 안내
- 번호 배지(예: `04 B04`) 클릭 → 설명 레이어(데스크톱 오른쪽, 699px 이하 하단 전체 시트): 번호·쉬운 이름·현재 어려움·바뀔 동작·시안 보기·선택 체크·함께 필요한 작업(자동 체크 안 함). ✕ / Esc / 바깥 클릭으로 닫히고, 연 버튼으로 포커스가 돌아갑니다.
- 선택은 `localStorage`(`numbered-20261025:selected`)에 저장돼 역할을 바꾸거나 새로고침해도 유지됩니다. 해제와 전체 해제를 할 수 있습니다.
- 선택 목록: 40개 전체(공통 X01–X06 포함) · 설명 · 시안 보기 · 현재 UI 위치 · 요청 문장 복사 · TXT/JSON 받기. 적용·배포 버튼은 없습니다.
- 요청 문장 형식: `개선 B04, C04만 이 시안대로 반영해줘.`
- 시안 안의 버튼은 “시안에서만 변경” 안내만 띄웁니다. 네트워크 연결, 저장, 발송, 지급은 일어나지 않습니다.
