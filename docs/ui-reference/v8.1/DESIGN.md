# THEPRLIST 검토 시안 디자인 기준 (v8, v7 토큰 유지)

조용하고 정돈된 업무 도구다. 기존 plum 색, 자체 SVG 아이콘, 한글 서체와 Slack형 프레임(레일·채널 사이드바·대화·상단 탭·하단 입력)을 유지한다. 그림자·그라데이션·대형 KPI·마케팅형 카드는 쓰지 않는다.

## 토큰 (현재값)
- 간격: 4 / 8 / 12 / 16 / 24 / 32 (`--s1`~`--s6`, design-v5.css)
- 반경: 6 / 8 / 12 (`--r1`~`--r3`)
- 색: 강조 `--c-accent #4a2c5a`, 보조 `--c-accent-2 #695177`, 강조 배경 `--c-accent-bg #f1ebf5`, 본문 `#1d1c1f`, 보조 글자 `#616061`, 선 `#e6e3e9`·`#d6d1db`, 표면 `#fff`·`#f8f7f9`, 레일 `#302137`, 사이드바 `#f3eff6`
- 의미 색 (칩·체크에만): 완료 `#1d6f47 / #e8f4ee`, 주의 `#8a5300 / #fdf3e1`, 오류 `#b42318 / #fdecea`, 정보 `#24508f / #e9f0fa`
- 글자: 페이지 제목 24px (모바일 21px), 섹션 16px, 본문 14–15px, 보조 13px, 힌트·라벨 보조 12px
- 컨트롤: 입력 40px, 버튼 38px, 터치 기기 44px (`--v7-ctl`, `--v7-btn`, quality-v7.css)

## 유지 규칙
- **최대 폭**: 폼 화면 1180–1200px, 표·대화 1440px, 채팅 화면은 v3 프레임 폭 그대로. 브랜드 학습은 입력 칸 760px까지.
- **배치**: 컨테이너 폭이 860px 이상이면 2열(입력 메인 + 280px 준비 현황 사이드), 그보다 좁으면 1열.
- **위계**: 제목 → 설명 → 페이지 행동(900px 이상에서는 제목 오른쪽). 페이지마다 주 버튼은 하나(`.btn.pri`)만 두고, 보조는 outline·ghost, 삭제는 붉은 글자 ghost로 분리한다.
- **상태 표시**: 색만으로 구분하지 않는다. 체크 표시 `✓`/`!`와 글자를 함께 쓰고, 진행률은 실제 데이터로만 계산한다.
- **목록**: 바깥 테두리 하나와 행 구분선만 쓴다. 행 높이 최소 56px, 이름은 15px 굵게, 보조 정보는 13px, 제품 이미지는 1:1로 고정한다.
- **입력**: 라벨(13px 굵게) → 입력 → 힌트(12px) → 오류(13px 붉은 글자, `aria-describedby`로 연결). 포커스는 2px plum 테두리.
- **한글 줄바꿈**: 본문은 `word-break:keep-all` + `overflow-wrap:anywhere`, 이메일·URL은 `break-all`, 숫자는 `tabular-nums`.
- **검토 툴바**: 제품 UI 바깥의 압축형 바.
  - 1100px 미만에서는 1행 역할 + ‘검토 도구’ 버튼, 2행 보기 전환으로 둔다.
  - 번호 보이기·선택·안내·페이지 링크는 접기 영역에 넣는다. 기존 노드를 옮기기만 하고, 접기 버튼은 `aria-expanded`와 Esc를 지원한다.
- **예시 표시**: ‘디자인 예시’ 표시는 본문 위에 하나만 둔다. 브랜드명은 상단 바·레일에 있으므로 브랜드 화면 본문에서는 반복하지 않는다(관리자 콘솔은 컨텍스트 바 유지).

## 근거
- 1728px에서 브랜드 학습 입력이 약 1370px까지 늘어나 읽기·입력 흐름이 끊겼다.
- 완료 칩 6개가 주 작업 위에 나열돼 있었다.
- 모바일 검토 툴바가 200px 넘게 차지했다.
- 목록에서 캠페인명·기한·상태가 같은 강조로 보였다.

## 통합 보완
- 좁은 학습 화면은 준비 상태 요약을 입력 위에 두고 상세 현황으로 이동한다.
- 320px에서는 검토 도구를 두 줄로 유지한다. 모바일 표의 값에 항목명을 붙여 숫자·상태의 의미를 보존한다.
- 세로 FAQ 필드에는 가로 행에서 쓰던 flex-basis를 적용하지 않는다.
- B02는 브랜드 학습으로 연결하며, 번호 링크를 최신 화면 매핑이 등록된 뒤 다시 해석한다.

## v8 추가 규칙 (visual-v8.css)
- **대화 카드 안쪽 선**: 회신·DM 대화(`.v6-iconvo`)의 머리말·메시지·메타 폼(상태·담당자·후속 할 일)·답장 입력·버튼 줄은 모두 같은 16px 안쪽 선에 맞춘다. 메타 폼은 회색 띠(`--c-bg-2`)와 위 구분선으로 묶는다.
- **폭 기준은 컨테이너**: 대화 3영역과 메타 폼 2열 전환은 viewport가 아니라 실제 본문 폭(container query)으로 정한다. 본문 720px 미만이면 1열, 메타 폼은 560px 이상일 때만 2열이다. 사이드바가 있거나 150–200% 확대해도 칸이 좁아지지 않는다.
- **크리에이터 범위 표시**: 내 할 일·내 캠페인 위에 `.v8-scope`를 둔다. 브랜드 내부는 항상 현재 브랜드의 제품·캠페인·보상·참여 기록만 보여 준다. 전체 브랜드 전환 필터는 두지 않고 공개 제품 탐색은 products.html에서만 제공한다. 선택한 브랜드와 다른 브랜드의 주소·캠페인을 기본 화면에 보이지 않는다.
- **가장 급한 일 하나**: 내 할 일에는 강조 카드 하나(96px 제품 이미지, 왼쪽 3px plum 선)만 두고, 나머지는 목록으로 보인다.
- **캠페인 카드**: 88px 1:1 이미지, 보상·신청 국가·콘텐츠·모집 마감(D-n)을 2×2 사실 칸으로, 하단에 내 상태 칩과 주 행동 하나를 둔다. 카드 2열은 목록 컨테이너가 760px 이상일 때만 쓴다.
- **진행 단계**: 신청 → 선정 → 조건·주소 → 샘플 → 영상 → 검수의 6단계 점·선을 쓴다. 완료는 ✓, 현재 단계는 글자 굵기와 테두리로 표시한다(색만으로 구분하지 않음).
- **미션 상태 3묶음**: 지금 할 수 있어요 / 조건을 기다려요 / 완료했어요. 행 버튼은 outline(주 버튼 금지)이고 ‘질문에 답하기’처럼 구체 행동과 장소를 쓴다. XP는 활동 기록이며 현금·정산과 무관하다고 표시한다.
- **랭킹**: 레벨 진행 막대, 내 행(plum 배경과 왼쪽 선), 상위 3위 번호 원만 강조한다.
- **고정 캠페인**: 채널 대화 스크롤 안 맨 위에 한 줄로 둔다. 고정 높이로 두면 좁은 화면에서 대화 영역이 줄어든다.
- **단계 알약**: 좁은 폭에서는 줄바꿈한다(겹침·잘림 방지).
- **운영 관찰 값**: ‘공용 9 / 오류 1 / 배정 가능 8 / 데모 1’ 같은 관찰은 날짜를 붙인 관찰 상자에만 쓰고, 계산·한도·성과로 쓰지 않는다. 200개 계정은 ‘가상 확장 예시’로 따로 표시한다.
- **v1 `.creator-wrap` 화면**(내 정보·도움말 등)도 시안 모드에서는 왼쪽 기준선에 맞춘다. 현재 캡처 모드는 바꾸지 않는다.

## v8 최종 검토 보완
- 받는 사람 선택 행은 체크박스와 이름을 가로로 정렬한다. 일반 grow 열 스타일을 상속하지 않는다.
- 기한 계산은 Asia/Seoul 업무 날짜를 사용하며 고정 예시 대화는 오늘 대신 최근 대화로 표시한다.
- 공지는 선택 브랜드의 예시 캠페인으로 연결하고 모바일 메뉴와 본문 레벨을 같은 상태로 표시한다.
